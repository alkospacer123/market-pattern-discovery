## Условия остановки и rollback

Любой unexpected active H1 Task/process, не-HALTED, authorization drift, изменённый checkout/state, source spoof, weak ACL/reparse, producer publication error, секрет в UI/log, public listener, missing Windows test или непроверенный account binding → STOP приёмки. Не восстанавливать H1 автоматически. Завершить только CC foreground processes и применить `Uninstall.ps1` из installation plan, сохранив data/evidence. Он удаляет только CC matching files/marked venv, не меняет H1, Tasks или ACL.

Финальный результат физической процедуры допускает CC03_PHYSICAL_PASS только при фактическом независимом source/ACL/before-after evidence и всех необходимых разрешениях. Если безопасного источника нет — SOURCE_BLOCKED / NEEDS_SOURCE_APPROVAL; панель DEMO/UNKNOWN может работать, но это не PHYSICAL PASS. Текущая итерация ни один пункт на Intel не исполняла.
