The future transport must publish immutable completed records after close/fsync into a separately owned local export root, with schema version, payload digest, source identity, monotonic sequence, original observed times, completeness, bounded size/retention and verified ACL/provenance. A corrupted latest record, changed source/account, unknown calendar/TTL or old observation must fail closed, without last-good authority. Credential/token material never enters UI or exported records. Source authority must be explicit per field: local intent, engine observation, authenticated broker snapshot or broker fill evidence are different levels.

Any producer change, new broker account access, consistent SQLite export or robot-side telemetry requires its own narrow operator decision and acceptance. This document grants none of them; this PR implements only independent Windows OS facts and CC-owned publication.
