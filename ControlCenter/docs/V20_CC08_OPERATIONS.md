## Что оператор должен видеть

- Главная: отдельно Shallow / OBV / Inside; статус + Heartbeat + Windows Task + Kill switch, последняя ошибка только при наличии. STAGING · LIVE OFF **не HEALTHY**.
- Журнал: отдельные раскрывающиеся блоки; **до десяти последних завершённых циклов** каждого робота (новые сверху), причина и результат, а также диагностика. Исторический FINAM READONLY **с рабочего экрана удалён**; справка хранится в этом offline-документе. Отсутствие событий не равняется нулю реальных торгов.
- Управление: 12 отключённых кнопок START / PAUSE / STOP / RESTART, без обработчиков. Пока нет отдельного разрешения, это **макет интерфейса**, не контроллер реальных роботов.
- Единственный действующий элемент — ручная кнопка «Обновить данные». Навигация вкладок, повторный rerun Streamlit и открытие экрана сами не должны опрашивать торговые источники.

## Свежесть данных

- Метка «Последняя проверка» — момент **попытки ручного обновления панели**. `—` до первого клика новой сессии — ожидаемо. Эта метка не означает успешное чтение.
- Heartbeat принимает `HEALTHY` только при подтверждённой свежести; просроченный свыше 300 секунд подтверждённый heartbeat — `UNHEALTHY`; при отсутствии проверенного источника — **НЕТ ДАННЫХ**, не `UNHEALTHY` и не `HEALTHY`.
- Историческая FINAM-квитанция наблюдалась **24.10.2026 09:07:32 МСК**. Она оставлена как архивное доказательство CC-05 и больше **не читается и не выводится из Streamlit** при ручном refresh. Старый PASS не подтверждает деньги, позиции или стопы сейчас.
- Windows Task `DISABLED` и workers `0` подтверждались для конкретных выполненных операторских проверок, не выдавать их за постоянную телеметрию.

## Минимальная реакция на инциденты

| Симптом | Реакция без торговых действий |
|---|---|
| STAGING · LIVE OFF / DISABLED | Нормальное состояние до запуска V20. Не включать Task из панели |
| НЕТ ДАННЫХ по Heartbeat или Kill switch | Не трактовать как HEALTHY или FAIL; нажать ручное «Обновить данные» и проверить отметку источника |
| STALE/UNHEALTHY при известном источнике | Оставить статус «не подтверждено», изучить Журнал и провести штатный отдельный readonly `check`; **не** перезапускать Task автоматически |
| Финансовая квитанция только историческая или источник недоступен | Не показывать текущие деньги/позиции; для актуальных брокерских данных нужна отдельная авторизованная READONLY-проверка, не Streamlit |
| Отсутствие доступа, SID mismatch, ACL/manifest mismatch | Остановить внедрение и диагностировать идентичность и источник; не повышать права панели для обхода |
| UI 8502 не открывается/искажён | Сохранить логи и установленную резервную копию; не изменять 8501 и торговые проекты; восстановление UI только отдельной операторской процедурой |
| Кнопки управления внезапно активны | Остановить приёмку новой сборки; такой UI не является CC-07 OFFLINE-approved; не нажимать команды |

## CC-08: согласованное упрощение рабочего Журнала (24.10.2026; Draft до CI и Intel)

- По решению владельца исторический `FINAM READONLY` и строка `Деньги PASS` исключены из рабочего Журнала. Панель `v20_app.py` больше **не импортирует и не вызывает `cc.v20_finam.acquire`** даже при ручном обновлении. Сам CC-05 модуль проверки и обезличенный архив остаются в `ControlCenter` для доказательств и могут проверяться отдельно от интерфейса, не потребляя торговых токенов.
- Журнал остаётся по трём независимым роботам и отображает только полученные подтверждённые события. Контракт `cc.v20.readonly.v1` строго принимает не более десяти отсортированных по времени `events` с полями `at,cycle,result,code`; UI показывает их **новейшими сверху**. Это не подтверждает, что V20 уже публикует полную ленту последних десяти циклов: V20 пока STAGING, действующий источник событий отсутствует. Дополнить источник **только отдельной авторизованной будущей разработкой V20**; менять frozen V20 сейчас запрещено.
- Исходная физическая приёмка Журнала от 24.10.2026 21:57 МСК относится к **предыдущему** UI. Повторная физическая приёмка FINAM-free интерфейса **PASS** (24.10.2026 22:22 МСК); сохранены оба этапа исторического доказательства, но отчёт FINAM не используется в текущем рабочем Журнале.
- Содержимое баланса и денежные суммы наблюдаются в FINAM-терминале, а не в Control Center. Остаются технические статусы Windows Task, heartbeat, отсутствие событий и причины ошибок.
