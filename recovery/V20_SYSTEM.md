# V20 Trading System — паспорт и границы

## Состав и frozen-логика
- Shallow Pullback: вход в направлении тренда после неглубокого отката, при выполнении точных замороженных условий исходного кода.
- OBV Pressure: давление объёма / нормализованная логика последних 12 баров; это **не** простая стандартная линия OBV из терминала.
- Inside Day Release: пробой диапазона внутреннего дневного бара по исходным правилам.
- Для каждого N4: USDRUBF, CNYRUBF, GLDRUBF, IMOEXF. Таймфрейм M15, решение по завершённым свечам, исполнение NEXT_OPEN.
- Начальный защитный стоп 2×ATR14 (Wilder), трейлинг 3.5×ATR14; риск на новую позицию 1.5%, общий cap 6% на счёт; один активный position per instrument per robot. Проверять фактическую реализацию exact tick grid/outward rounding, расчёт размера по исполняемому стопу, комиссию и ГО.
- Вход/выход/фильтры строго frozen; любое изменение = отдельный исследовательский кандидат и полный доказательный цикл, не «тихий фикс».

## Архитектура
Три изолированных FINAM торговых счёта / токена / DPAPI CurrentUser / SQLite / Task, общий READONLY токен при принятой диагностике. Общие модули исполнения и контроля, но не общая управляющая authority. Операторские скрипты — `C:\V20Lab\pretrade-08\live-08\v20-08-live-operator.ps1` и локальные READONLY команды. Не публиковать account IDs или DPAPI-маршруты. Восстановление секретов на новой Windows может потребовать перевыпуска токенов и SID binding.

## Риски, governance и запреты
- Стоимости: research C1; LIVE — реальные комиссии биржи/брокера. Нет ML и самовольной оптимизации.
- Аварийная остановка должна быть fail-closed, с учётом broker truth и открытых позиций. STOP/PAUSE в Control Center не эквивалентны закрытию рыночной позиции.
- H1 frozen/paused, standalone M15 не активировать ради V20.
- Новые идеи (фильтр 1×/1.5×/2× дневного ATR и limit-entry passive/aggressive/sliced) — **гипотезы TRL, не утверждённые LIVE-параметры**.
- Исследования моделей капитала (50/50, динамический резерв, N4 и 1/1/1…4/4/4) архивированы; 04.11 решено сохранить **действующую** модель ГО без изменений.
