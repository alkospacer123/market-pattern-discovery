## II. Полномочия, безопасность и доказательства
Единственный оператор — пользователь. GPT/Codex и Kimi AI/Kimi Code — технические партнёры с проверяемыми отдельными правами, аудитом, ветками и review; не конкурируют на одних торговых счетах. **Без отдельного явного допуска запрещены** Merge, реальное удаление файлов/репозиториев/веток, force push/history rewrite, установка, изменение LIVE/FINAM/SLTP/DPAPI/Windows Tasks, торговых сигналов/рисков, денег и брокерские POST. Разделять `MAIN` (Git), `INSTALLED` (Intel), `LIVE` (Windows/FINAM/позиции), `RESEARCH` (тесты), `ARCHIVE` (история), `RECON` (реконструкция). Git Merge ≠ installed ≠ LIVE; Task Running ≠ ARMED; HTTP 200 ≠ broker proof. Для факта: источник, дата, SHA/хеш, границы проверки, PASS/FAIL/UNKNOWN. UNKNOWN не подменять PASS.
