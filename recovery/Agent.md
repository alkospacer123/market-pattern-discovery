## Действующие системы
**V20:** три робота Shallow, OBV, Inside; N4 USDRUBF/CNYRUBF/GLDRUBF/IMOEXF, M15 NEXT_OPEN, SL 2×ATR14, риск 1.5%/6%, TP6 + Protect3 + HOLD5, EXT2 OFF, целевая модель 60/30/45. `main` содержит базовый `finam_live.py` и девять патчей для релиза R088, а не идентичный готовый installed-файл. Последний релизный свидетель — Running/HALTED 3/3, последующий ARMED не подтверждён.

**Control Center:** панель 127.0.0.1:8502, экспортёры, Windows, CC-07. Health UI/heartbeat, Task Running и успешная операторская команда не эквивалентны broker truth. Действия с реальным LIVE требуют отдельного допуска.

**TRL:** Research, Evolution, Journal, отрицательные результаты и доказательства. Итог 60/30/45 принят после R097/R098, но исторический лидер по Net/PF 75/30/30 не удалять. Не выдавать многократно исследованную историю за TRUE OOS; без разрешённых READONLY-отчётов финансовый блок HOLD_DATA.

## Права и безопасность
GPT/Codex и Kimi Code должны иметь равную проверенную возможность доступа к необходимому принятому коду, веткам, тестам, PR, CI и отдельным изолированным рабочим копиям. Отдельные авторизация, аудит, review, передача незавершённой задачи. Kimi Chat не означает автоматически действующий Kimi Code.

**Без разрешения оператора запрещены:** изменение алгоритмов/рисков, отправка или отмена заявок, перезапуск или переключение LIVE, FINAM/DPAPI операции, изменение счетов/токенов, merge, удаление репозиториев/веток/данных, перезапись истории. Не запускать конкурирующие LIVE на одних счетах. Не повторять брокерский POST при неизвестном исходе.

## Исследования, Recovery и дорожная карта
Baseline → optimization → robustness → walk-forward → TRUE OOS только по реальному протоколу; расходам C1 не приписывать реальные биржевые затраты. Не менять LIVE по исследовательскому итогу без разрешения.

Порядок проекта: **R0 → R4 → защитный снимок → R7 → R1 → R2 → R3 → R5 → R6 → R8**. R7 — **один общий рабочий** `market-pattern-discovery` с шестью сохраняемыми каталогами, отдельные `market-pattern-data` и пустой публичный `market-pattern-archive`; `market-pattern-autonomous-engine` уже удалён самим владельцем (GitHub 404); повторять удаление/инвентаризацию не нужно, архив его истории не подтверждён. Остальные необратимые операции R7 требуют независимого защитного снимка и разрешения.

Windows: однострочный PowerShell в нижнем регистре без GUI, установленный/venv Python вместо `py.exe`. Cold restore только в изолированной среде без торговли; SHA256 не является доказательством восстановления. Секреты и частные журналы не помещать в публичные AI-пакеты.

## Правило продолжения
Перед каждой задачей установить проект, контур, дату, проверенный источник и последнее разрешение оператора. Предлагать наименьшее безопасное изменение с тестами, журналом доказательств и откатом. Не повторять выполненные исследования ради формального заполнения этапов.
