# Trading Research Lab — проект долгосрочных исследований

## Миссия и три направления
TRL = **Research** (поиск стратегий/технологий/гипотез), **Evolution** (оценка V20 и будущих систем по доказательствам), **Journal** (неизменяемая хронология результатов, отрицательных идей, решений). `TradingResearchLab/` на GitHub — текущая основа, не требуется отдельная сложная платформа.

## Статус и регламент
- 31.10.2026 `TRL-00` **CLOSED / ACCEPTED WITH DOCUMENTED LIMITATIONS**. Формальные отчёты, инвентаризация, шаблоны и рабочий цикл принят, но архивы V1–V24 большей частью не проверены, live financial READONLY источник не готов.
- `TRL-01` — первый **декабрьский 2026** месячный обзор. `TRL-02` — первая исследовательская четверть 2027; `TRL-03` — оценка процесса весной 2027. Не выдумывать завершение будущих этапов.
- Ежемесячно: обзор новых идей и технологий, READONLY-анализ V20, список приоритетов; ежеквартально — минимум одна проверка новой стратегии и одно исследование потенциального улучшения при достаточности данных; ежегодно — эффективность и стратегия развития; значимые решения — Journal сразу.
- Источник идеи → механизм edge → frozen определение → quality gate → baseline → оптимизация только по разрешённому TRAIN → robustness → WFA → независимый OOS (по контракту конкретного исследования) → REJECT/CONTINUE/CANDIDATE → отдельно разрешённое LIVE внедрение.

## Действующие ограничения
- V20 frozen. Сбор данных для Evolution только из **отдельной готовой обезличенной READONLY-копии**, полученной из LIVE-проекта. TRL не читает напрямую FINAM, токены, production SQLite или Windows Tasks.
- Не путать CC-02 health snapshot с финансовым трейд-леджером: пока нет подтверждённых gross/net P&L, комиссий и equity, денежные метрики `NOT_AVAILABLE` / `HOLD_DATA`, не ноль.
- Исторические серии 2018–2026 много раз исследовались; считать их чистым новым TRUE OOS без проверки невозможно. Не перерабатывать V1–V24 только ради заполнения отчётности.
- Никаких новых live сигналов без соответствующего отдельного рассмотрения и approval.

## Исторические и новые гипотезы
1. Дневной ATR-distance entry gate: проверка запрета после достижения 1 / 1.5 / 2+ дневных ATR от открытия с разбивкой по Shallow/OBV/Inside и N4. **Исследование предложено, финальный результат отсутствует**.
2. Limit-entry вместо рыночного: пассивный лимит, агрессивный +тик, исполнение частями; требуются рыночные данные достаточного разрешения / моделирование очереди, нельзя утверждать fill по OHLC.
3. Сравнение действующей ГО-модели и резервных моделей (50/50, динамический, N4) архивировано; 04.11 решение — LIVE модель не менять.
4. Qualification/КПУР и снижение ГО — исследование условий FINAM/брокера; не принимать снижение ГО на 50% как уже подтверждённое или автоматически вытекающее из статуса инвестора.
