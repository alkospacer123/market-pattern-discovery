# RECOVERY MEMORY — независимая память трёх проектов

**Срез знаний:** 2026-11-09 (МСК). **Статус:** RECONSTRUCTED / NEEDS SOURCE RECONCILIATION. Это самостоятельный слой документации, а не замена исходного кода, отчётов, журналов или полного экспорта ChatGPT.

## Цель
При потере аккаунта ChatGPT, GitHub или Intel-компьютера восстановить **три самостоятельных проекта и преемственность решений** без повторения исследований: (1) V20 Trading System — LIVE и отдельное сопровождение, (2) Control Center — мониторинг и операторское управление, (3) Trading Research Lab (TRL) — поиск и развитие стратегий. Рабочие программы восстанавливаются из проверенного SSD-архива; GitHub хранит обзор, доказательства, методологию и инструкции для следующего ИИ.

## Граница и конфиденциальность
**Не хранить здесь** FINAM-токены, пароли, DPAPI-материалы, идентификаторы счетов/заявок, персональные данные, сырые журналы, production SQLite, незашифрованные полные чаты и исходные котировки. Репозиторий публичный. Полные копии V20 и Control Center — отдельно на защищённом внешнем SSD. Архивы H1/M15 (~125 ГБ) **не входят** в данный scope, будут разобраны отдельно. Исходники и документы H1/M15 в существующих репозиториях не меняются.

## Степень полноты
Это обширная **реконструкция доступной проектной памяти**, а не доказательство полноты всех разговоров. Отдельные сообщения, вспомогательные артефакты и точные временные отметки могут отсутствовать. Экспорт ChatGPT повторно запрошен, его получение на момент среза **не подтверждено**. Когда появится первоисточник, сверить и дополнить документы, не переписывая историю задним числом.
