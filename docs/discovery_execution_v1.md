# Discovery Execution Contract v1.0

This signed contract freezes the target-independent Phase 5B execution path. The normative machine-readable source is `config/discovery_execution_v1.json`.

Features are classified solely by frozen names and domain semantics: boolean/touch/cross/state flags are binary; calendar and finite counts are integer categorical; candle direction is categorical; all remaining predictive measurements use frozen continuous quantile states. No outcomes participate. Continuous states are `LE_P10`, `P10_P25`, `P25_P75`, `P75_P90`, `GE_P90`, `MISSING`; ties enter the lower interval. Full discovery fits within the applicable DISCOVERY instrument/timeframe and walk-forward fits TRAIN only.

Enumeration uses CNY, Si; M1, M5; frozen feature index; canonical state; target-mapping order; contrast order. Pairs allow same and cross family, use `i < j`, and retain the first 500. Subgroups enumerate depths 2 then 3 and stop at 100,000 without outcome-dependent selection. Attempted and duplicate hypotheses remain accountable.

The baseline is all target-valid rows in the same instrument, timeframe, and DISCOVERY interval. Effects retain signed and absolute values. Complete Moscow-date bootstrap and the complete-day null permutation each use 1,000 replicates and seed 20260401. Raw two-sided p-values use `(1 + exceedances)/(B + 1)`. BH uses the frozen target-mapping family without result-driven splitting.

Only promoted effects enter the canonical research registry, initially as `discovered`, then transition to `screened`. Replication, ranking, shortlist, preregistration, finalization, deterministic batching/checkpoints, artifact schemas, and complete reconciliation are frozen by the signed JSON. No partial run may pass reconciliation.

This phase analyzes no feature/outcome relationships, creates no candidates, accesses neither confirmation nor 2025, calculates no profitability, and runs no backtest.
