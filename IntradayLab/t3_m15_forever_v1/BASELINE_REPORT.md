Это независимый фиксированный исторический replay 2023–2024. Новая оптимизация, Robustness, Walk Forward, TRUE OOS и подбор фильтров не запускались. Две версии — контрольные варианты; победитель не выбирается.

Gate A: **PASS**. Gate B: **PASS** для нормализованной исследовательской модели C1.

C1: один исследовательский тик на сторону. Si/CNY сохраняют 0.001; GLD — 0.1 RUB, IMOEX — 0.5 пункта. Масштаб новых инструментов подтверждён датированными объявлениями MOEX; все исторические OHLC проходят Decimal-проверку сетки. R и стоимость считаются в одной ценовой единице; RUB-множитель сокращается. См. SPEC_EVIDENCE.json. Полные архивные DOC недоступны; исчерпывающая историческая контрактная аттестация не заявляется.

История не выравнивается: USDRUBF/CNYRUBF с 03.01.2023; GLDRUBF с 11.07.2023; IMOEXF с 14.11.2023. Прогрев начинается с доступного старта каждого инструмента, минимум 75 завершённых H1-контекстов плюс slope lookback. Никаких предысторий вне периода. 2023 IMOEXF — короткий неполный год.

## Границы экономического вывода

По закрытым сделкам фиксированной нормализованной модели C1 каждая из двух версий имеет положительные Net R и expectancy на каждом инструменте за доступный период 2023–2024. Это самостоятельный результат исходной логики без дополнительных фильтров. Уверенного устойчивого преимущества на четырёх инструментах не установлено: слабый валютный 2024, отрицательный исторический WF, зависимость отдельных годовых результатов от пяти лучших сделок и короткая история новых контрактов ограничивают вывод. У IMOEXF по одной открытой позиции в каждой версии на конце префикса; их выход и окончательная экономика НЕ РАЗРЕШЕНЫ. OPEN_POSITIONS.json показывает направление, Stop, последнюю цену и нереализованный Gross R без выдуманного выхода.
