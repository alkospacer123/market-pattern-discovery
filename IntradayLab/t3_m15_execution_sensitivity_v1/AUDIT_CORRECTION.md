# Исправление ключа сводной таблицы после первого результата

Первый historical Next Open выполнен после удалённой заморозки c0a107e6. Initial freeze сохраняется в Git. Первичный replay завершился, CONTROL PASS; первая попытка независимого аудита дошла до последней comparison.csv таблицы и аварийно остановилась: KeyError 'rule'. Ни независимый AUDIT_RESULT PASS, ни итоговый PR до исправления не заявлялись.

comparison.csv содержит текстовую model, но не внутренний rule. Исправлена ровно одна строка audit.matches: если rule отсутствует, использовать фиксированное отображение A6+S1→C1, T1→T1, T1+S1→COMBINED. Это исправление схемы аудита, не стратегии/параметров/индикаторов/исполнения/анализа. Все остальные Python/spec/protocol bytes остаются равны initial freeze. На синтетическом schema regression проверены три модели и оба способа ключа.

Code freeze обновлён отдельным correction commit до повторного полного независимого аудита. FREEZE.json явно хранит initial_preresult_commit и corrected commit; не утверждается, что исправленный audit существовал до первого результата. FIRST_PRIMARY_SHA256.json фиксирует все первые артефакты до исправления. Новый primary replay обязан дать те же байты всех торговых CSV/JSON и читаемого отчёта; допустимо изменяется только SOURCE_MANIFEST.json, записывающий correction SHA. Два свежих полных повтора после этой correction также обязательны.

Первоначальный audit.py доступен в initial Git freeze; его ошибка не скрывается. Торговые вычисления не изменяются после просмотра результатов. Внешнее независимое человеческое ревью PENDING.
