# Замороженный протокол до первого исторического Next Open

Статус: GROSS_ONLY / COSTS_DEFERRED / NOT_LIVE_READY. 2023–2024 DEVELOPMENT_EXPOSED.

Ровно A6+S1 (C1), T1 и T1+S1 (COMBINED), каждая BASELINE 3.0 ATR / OPTIMIZED 3.5 ATR. Это проверка исполнения, не оптимизация. Все остальные параметры и причинные индикаторы из #497/#499/#500 сохраняются. Первичный критерий — Gross PF ≥1.70 отдельно в каждом году; предпочтительно >2 ежегодно. Месячная регулярность равноправна: ориентир 20–24/24, меньшая концентрация одного месяца без ухудшения DD и разрушения больших победителей. Никаких новых численных cutoffs/составных scores.

CONTROL обязан воспроизвести полные опубликованные CLOSED, terminal OPEN, Stop, entry, gap/period OPEN (где опубликованы), занятость и хронологию. Точность 1e−8; исходные PF/R после соответствующего округления. При несовпадении все новые расчёты блокируются. Первичная сверка уже прошла, независимый scalar CONTROL прошёл; в каждом новом прогоне gate повторяется до Next Open.

Сигнал — только завершённый M15 Close. Next Open — Open следующей реально наблюдаемой свечи только при close(next)−close(signal)=15 минут. Entry open timestamp равен signal Close, но цена может отличаться. Решение исполнить pending использует лишь timestamp и Open; High/Low/Close исполнения не участвуют. Gap отменяет pending, не переносит его на произвольный будущий Open; отсутствующий следующий бар — отдельный UNRESOLVED_END_OF_DATA, без исполнения и обращения к 2025+.

**До первого нового результата фиксируется формула:** initial Stop = actual entry − side × 2 × ATR завершённого сигнала; immutable initial R = abs(actual entry − initial Stop). Симметрично LONG/SHORT. Stop действует с момента входа: на свече исполнения adverse intrabar touch закрывает по Stop. На последующих свечах adverse Open через Stop закрывает по Open. Сначала Stop, только затем extrema пережитой свечи. Signal-candle extrema исключены. S1 может активироваться на Close пережитой execution candle, никогда раньше; ratchet действует с следующей наблюдаемой свечи. S1 threshold 1R неизменен, Stop не ослабляется. T1 без S1 trailing работает после первого пережитого execution Close.

T1 проверяет signal Close [10:00,18:00) МСК. A6 сравнивает последнее завершённое H1 ATR/ATRMean с предыдущим, строго >; исходный H1 ATR/ATRMean>1 сохраняется. H1 — daily ordinal-группы четырёх смежных M15, неполные/gapped пропускаются без перепаковки. Рекурсивные EMA/ATR/ADX, Donchian, позиции, первоначальный риск и S1 пересекают сессии и границу 2023/2024. Не принудительно ликвидировать OPEN. Годы/месяцы CLOSED — историческая Close-метка выхода. На границе 2025 не читать будущий OHLC; использовать тот же закрытый интервал Close<2025-01-01, что CONTROL.

Пересчитываются вся траектория, занятость, повторные входы, skipped/filtered/busy, Stops и terminal/period OPEN. Занятость — stop-checked observed bars / observed bars excluding first per instrument; gaps не синтезируются. CLOSED-R DD — накопленные закрытые R с 0, порядок exit_time/instrument/trade_id. Не капитал/MTM доходность. MFE/MAE считают пережитые свечи, exit-candle favorable экстремумы не используются.

Фиксированные отчёты: 2023, 2024, общий период, все 24 месяца; все инструменты × LONG/SHORT; поздние GLD/IMOEX NO_COVERAGE; expectancy/CLOSED/OPEN, положительные месяцы, худший месяц, серии отрицательных месяцев/сделок, DD, top1/top3 annual month shares, ex-top1/ex-top3 PF/R, top5/top10 winners, November sensitivity; исходные CLOSED ≥2R/≥5R по signal identity, сохранённый/изменённый R, потерянный вход/terminal OPEN; новые входы и mean entry-price deviations. Полные отрицательные результаты сохраняются.

Исключения месяцев — только арифметическая sensitivity существующих CLOSED, не новые replay. Дополнительных counterfactual replay нет; цена и пропуски меняют Stop/занятость/следующие входы совместно, поэтому им не приписывается отдельный численный вклад в ΔP&L. Signed entry deviation — только расстояние цены, не P&L attribution.

Две реализации: локальные dataframe features + object state machine; локальные stdlib streaming recursive features + отдельная dict state machine. Аудит имеет собственную scalar арифметику и не импортирует primary engine/analysis. Исходники адаптированы из отдельных проверенных #500 реализаций, новые правила Next Open написаны раздельно в текущей сессии. Автор один; независимость вычислительная, внешняя человеческая проверка PENDING.
