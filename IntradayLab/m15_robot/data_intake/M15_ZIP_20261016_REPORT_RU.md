## Независимое разрешение источникового Volume-конфликта — 16.10.2026

[Полный отдельный источник-аудит №08](STEP08_IMOEXF_M5_CONFLICT_RESOLUTION_20261016.md) проведён по **реально прочитанным** pinned `IMOEXF_M5.csv` и `IMOEXF_M15.csv` из `market-pattern-data@f8486b446cf3d5f9f3cba6dfec32bdef8fd184c8`.

Для IMOEXF OPEN 09.09 07:00 МСК три архивные M5 дают **8745 + 6260 + 4776 = 19781**, OHLC агрегированного M15 **2279 / 2279,5 / 2273,5 / 2276**. Это в точности соответствует M15.zip по ранее выполненному аудиту; frozen M15 содержит те же OHLC, но Volume **19786** (+5). Проверен весь день: 203 M5, 68 M15, 67 полных наборов M5→M15, **66 полностью совпадают и ровно один отличается только по Volume**.

**Решение:** исключение *объяснено межтаймфреймовой сверкой*, но биржевая первопричина старого значения +5 не установлена. Frozen M15 **оставить 19786**, старые 77 дополнительных свечей и конфликтующую строку **не встраивать**, кандидат продолжения 9120 — исключительно после terminal pinned. `immutable_prefix_splice()` на полном конфликтном пересечении обязан продолжать отказ; никаких допусков ±5 не вводить.
