## Проверенное исходное состояние и граница чтения

Новый запуск выполнен непосредственно в опубликованном checkout, без восстановления worktree, ZIP или патча. До изменений чистый checkout `main` и актуальный GitHub `main` совпали с `b191a94c306db972195549d4604b500973519cdf`. Ветка создана от этого HEAD: `research/intraday-stage1-2-sessions-mtf`. Python **3.12.14**; дополнительные зависимости отсутствуют. Все 16 CSV доступны на чтение; IntradayLab доступен на запись; GitHub API подтвердил право push.

Источник: `alkospacer123/market-pattern-data`, HEAD `f8486b446cf3d5f9f3cba6dfec32bdef8fd184c8`, `/workspace/market-pattern-data/forever`. Индексные blob ID всех файлов сверены с неизменённым frozen manifest. Полные CSV не хешировались: это потребовало бы чтения TRUE OOS. Проверка индексных ID подтверждает индекс, а не повторно проверенное содержимое всего файла. Целостность входа опирается на чистый исходный checkout, manifest, SHA-256 прочитанного префикса и неизменность метаданных при чтении.

Обработано **458 866 исторических строк**, **25 970 687 байт** префиксов, включая заголовки. Из строк **445 633 относятся к 2023–2024**, **13 233 — к 2022** в ранней истории USD/CNY M30/H1. Последние проверены при загрузке и сравнении состава, но расписание 2022 года в этот аудит не входит. Самая поздняя метка — 30.12.2024. Одна и та же история повторно обработана для проверки детерминированности; это не дополнительные уникальные строки.

`read_prefix` открывает CSV как unbuffered `FileIO`. `bounded_lines` получает ровно `manifest.rows + 1` LF-терминированных строк: заголовок и исторические записи. Каждый read запрашивает не больше оставшегося количества LF; один байт содержит максимум один LF, поэтому запрос не может пересечь последний разрешённый LF. Следующей строки и EOF-пробы нет. Заголовок, ticker, порядок, OHLCV, first/last сверяются; timestamp проверяется до разбора чисел. Число строк не определяется сканированием будущего хвоста. Предпосылка — доверенный неизменённый manifest и соответствующий checkout; смещение строк в изменённом входе не считается допустимым режимом.

**PASS:** физическая граница чтения проверена защитными потоками и подклассом `FileIO`, запрещающими любой запрос за концом исторического префикса. **0 байт TRUE OOS** прочитано диагностическим аудитом; будущие строки, даты, цены, объёмы и статистика не исследовались. Старый `audit_forever.py` прочитан как код для проверки ограничения, но не запускался.

## Timestamp и проверка состава

В CSV наивные временные метки без timezone. README источника не содержит аттестации timezone/start/end. **MSK — гипотеза**, поддерживаемая историческими часами биржи и наблюдаемыми паузами, но не доказанная совпадением цен.

При start-label гипотезе M5 группируется по сетке 00/15/30/45, 00/30 или началу часа. Полный состав должен содержать ровно 3/6/12 ожидаемых меток M5. Все пять полей совпадают **точно**, без float-допуска:

| Инструмент | M15 полных совпадений | M30 | H1 |
| --- | ---: | ---: | ---: |
| USDRUBF | 26 148 | 11 618 | 4 690 |
| CNYRUBF | 24 274 | 10 428 | 4 049 |
| GLDRUBF | 17 210 | 7 216 | 2 691 |
| IMOEXF | 12 982 | 5 489 | 2 100 |

Неполные общие составы также совпадают по OHLCV, но **не допускаются** в MTF. При альтернативе, что все метки обозначают конец, полные составы почти всегда расходятся: всего 7 случайных полных совпадений M15, 0 M30/H1. Это сильное свидетельство относительного start-позиционирования, не доказательство абсолютной timezone и не независимая документация каждого TF. Проверены две одинаковые семантики всех TF; смешанные поставщицкие схемы этим не исключены.

Обнаружены дополнительные нарушения покрытия:

- 31.08.2023 USD/CNY: **0 M5, 0 M15**, но по **31 M30 и 16 H1**. GLDRUBF в этот день присутствует на всех TF. Причина пропуска экспорта **UNRESOLVED**; полнота дневного M5 **FAIL**.
- USD/CNY старшие свечи без M5 bucket: M30 **346/350**, H1 **331/335** соответственно. Большинство меток утренние 08:30/09:30 и 08:00/09:00, остальные включают 31 августа. Они не получают контекст без полного M5-состава; происхождение/аукционная семантика **UNRESOLVED**.
- 16.08.2024 USD/CNY: M5 и M15 продолжаются до 23:45, M30/H1 заканчиваются 18:30/18:00. По **10 M30-bucket и 5 H1-bucket** M5 не имеют старшей свечи. Библиотека блокирует соответствующие отсутствующие родители, не продолжает старый дневной контекст.
- IMOEXF: **128 M5-bucket с якорем 09:45** с 01.07.2024 до 30.12.2024 не имеют M15-родителя. После поправки режима это группы с наблюдаемой аукционной меткой M5 **09:55**, а не доказательство пропуска обязательной M5-свечи 09:45 или обычного непрерывного MTF. ## Минимальная библиотека и ограничения API

`tools/session_mtf.py` предоставляет `Bar`, `TimestampEvidence`, `SessionWindow`, `BlockedInterval`, `Decision`, `aggregate`, `align_contexts`, `bounded_lines`.

`TimestampEvidence` требует подтверждённые IANA timezone, start/end-label и независимые ссылки на метаданные всех входных TF. `SessionWindow` требует явные границы, ID, trading_day и подтверждающие источники. Значения по умолчанию ничего не аттестуют. Это интерфейс передачи уже проверенных фактов; строка URL сама по себе не проверяется сетевым запросом и не доказывает достоверность. В этом аудите реальные evidence/windows **не подтверждены и не передаются**.

Правила согласования:

1. Решение observable только в момент закрытия M5; `observed_at` не позволяет выдать более поздние решения. Родитель закрыт не позже этого момента; известная задержка доставки тоже учитывается.
2. Выбирается последний **ожидаемый по сетке** закрытый M15/M30/H1. Если его нет/он ещё не доставлен, старый родитель не подставляется.
3. Проверяется каждый ожидаемый M5-slot, ровно 3/6/12 в родителе и точный OHLCV через Decimal. Проверка охватывает также перенос контекста до текущего закрытого M5.
4. Любой пропуск/задержка M5 блокирует перенос; допуск возможен только после закрытия нового полного родителя после пропуска.
5. Родитель, все дочерние свечи и момент решения должны принадлежать одному подтверждённому непрерывному окну. При клиринге, halt, неизвестной границе или следующем окне сброс; интервалы через границу запрещены.
6. Карантин проверяется по пересечению интервалов, включая перенос старого контекста. Некорректный порядок, дубликаты, несовместимая сетка, смешение инструментов и перекрывающиеся окна отвергаются.

Библиотека не восстанавливает бары, не разрешает неизвестный календарь и не является движком стратегии/исполнения. Наивные метки допустимы только с внешней аттестацией общего feed-local clock. Сетка фиксированная календарная; иной подтверждённый механизм якорения потребовал бы отдельной проверки перед применением. Нет доказательства реальной задержки доставки или доступа к финальному OHLCV непосредственно в nominal close; при известной задержке используется `available_at`, при неизвестной реальные сигналы не разрешены.
