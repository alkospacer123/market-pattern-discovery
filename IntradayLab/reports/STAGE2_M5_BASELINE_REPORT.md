| Константа | Значение, заданное заранее | Основание |
| --- | --- | --- |
| ATR / breakout range | 12 предыдущих M5 | Простая часовая шкала; ни свеча сигнала, ни будущее не входят |
| Warm-up | 13 предыдущих непрерывных M5 | Для 12 true ranges нужен предыдущий Close; сброс на окне/пропуске |
| VWAP deviation/return | 1 ATR, симметрично | Фиксированное отклонение без поиска по инструментам |
| Stop | 1,5 ATR от Close сигнала | Единый масштаб защиты |
| VWAP Take / Momentum Take | VWAP сигнала / 3 ATR | Возврат к якорю / номинальное 2:1 к Stop |
| Удержание VWAP / Momentum | 60 / 90 минут | Ограничить fade; дать продолжению немного больше времени |
| Неблагоприятный cap входа | 0,25 ATR | Ограничить ухудшение при неизменных абсолютных Stop/Take |
| Availability / decision / order delay | t+10m / 0 / 0 | Явный ограниченный сценарий; исполнение всё равно строго позже ready |
| Entry TTL | Один заранее выбранный полный M5 | Без переноса заявки и погони за выгодным баром |
| B−30 / B−20 / B−10 | Запрет входа / инициировать close / цель подтверждённого flat | Неизменённый резерв PR #440 |

**VWAP — OHLCV approximation.** `typical=(H+L+C)/3`, VWAP = сумма typical×Volume / сумма положительных относительных весов в текущем исследовательском окне. Общая нормализация весов сокращается; единицы контрактов/ликвидность не предполагаются. LONG: предыдущий Close ≤ предыдущий VWAP − ATR, текущий Close > текущий VWAP − ATR, но < текущего VWAP. SHORT симметричен. ATR для обеих сравнительных границ — одно строго shifted значение на момент сигнала. Take заморожен как VWAP сигнала; это не динамически улучшаемый выход. VWAP/контекст сбрасываются при новом окне и после отсутствующей свечи.

**Momentum.** LONG при Close сигнала строго выше max(High) предыдущих 12 M5; SHORT ниже min(Low). Это эквивалент `rolling(...).shift(1)`: свеча сигнала не участвует в своём уровне. ATR — среднее 12 предыдущих true ranges, исключая сигнал. Momentum использует ценовые признаки без фильтра ликвидности по Volume; нулевой Volume не запрещает его ценовые признаки. Положительные веса требуются для VWAP. Во всех фактических 2023-префиксах нулевых Volume нет.

Все значения едины для четырёх инструментов. LONG/SHORT, одна независимая условная ценовая экспозиция на запуск; без усреднения, доливок, реального q, capital sizing, GO-подстановки или портфельных процентов. R = Net_model_C1 / первоначальная дистанция Entry→Stop; это нормализованная мера модельной сделки, не доля капитала. Риск 0,25–0,5%, дневной/недельный лимиты roadmap остаются исследовательскими целями и здесь не реализованы. Оптимизатора, grid, ранжирования конфигураций и ML нет.

## Время и исполнение

Исследовательские окна `[10:00,14:00)` / `[14:05,18:50)` MSK приняты пользователем для ограниченного сценария, не объявлены полностью аттестованными историческими сессиями. 13–20.03.2023 второе начинается 14:15, с 21 марта 14:05. Внеплановый halt 13.09.2023 не превращён в заранее известную границу/выгодный выход: обычное окно, отсутствие слотов обнаруживается только при ожидаемой доступности. Возобновление ценового контекста требует новых наблюдений и полного warm-up; неизвестный исход заявки сохраняет запрет новых входов независимо от восстановления контекста.

`[t,t+5m)` → OHLCV/решение в `t+10m` (либо позже известной доставки) → ready → первый полный разрешённый M5 со start **строго > ready**. При текущих нулевых дополнительных задержках это t+15m. У заявки заранее известен только слот, не его существование/Open/High/Low/Close/Volume. Защита/cap/TTL фиксированы по доступному сигналу. Исполнения и их подтверждения отделены от сигнала: подробный журнал содержит интервал, модельный reference, requested/filled/residual и confirmed_at. Intrabar timestamp неизвестен.

Marketable-entry/close: условный полный fill абстрактной единицы по Open выбранного полного бара. Это отдельно принятое **MODELLED** допущение, не доказанная биржевая ёмкость. Cap/порядок Stop<Entry<Take проверяются постфактум на Open; при нарушении NONFILL, остаток заявки явно отменяется по TTL. Пропущенный целевой бар не создаёт ни fill, ни доказанный NONFILL: исход уже отправленной заявки остаётся неизвестным. Подтверждённый NONFILL по известному Open/cap или синтетической нулевой capacity и pre-target gap-cancel сохраняется. Не используется `floor(1%×Volume)`. Частичные исполнения проверяются синтетическим adapter в целых абстрактных единицах; в восьми фактических сценариях PARTIAL = 0, дробные реальные контракты не изобретены.

Resident Stop: при гэпе long — min(Open,Stop), short — max(Open,Stop), иначе модельное касание Stop. TP только при проходе минимум на действующий tick, reference не лучше Take; касание не исполняется. Stop-first при двустороннем баре; entry-bar TP запрещён, неблагоприятный Stop допустим и помечен AMBIGUOUS_ENTRY_EXIT. Упорядоченность тиков/очередь OHLCV не реконструируются.

Max-hold close инициируется в Entry_bar_start + max_hold − 5m; первый строго более поздний бар при непрерывном сценарии достигает max_hold. Close B−20, целевой подтверждённый flat B−10. После исправления осталось **12** нарушений при известной модельной позиции (раньше 160): закрытие по Open B−15 становится подтверждённым по OHLCV только B−5. Дополнительно **8** неизвестных заявок не получили подтверждённого flat к B−10 своей исходной границы; всего **20** записанных нарушений. Для неизвестной заявки B−20 записывает требование reconciliation/emergency close без выдуманной исполненной quantity, B−10 — неопределённость flat. Счётчик фиксирует исходную границу один раз на заявку, а не объявляет flat в последующих сессиях. Известные условные позиции закрылись до B/конца 2023; возможная неизвестная экспозиция **не признана закрытой**. Holding — разность start-меток, точное intrabar время неизвестно.

Отсутствие свечи обнаруживается на t+10m: контекст сброшен, открытый остаток сохраняется, аварийный close отправлен причинно, последующие отсутствующие выходные бары записаны NONFILL. Если pending-entry мог исполниться до обнаружения пропуска, успешная отмена задним числом не присваивается: возможная экспозиция резервируется, после модельного acknowledgement сохраняется UNRESOLVED и инициируется emergency close. Эта проверка исправила причинный дефект первоначальной реализации; параметры не менялись. Отдельные коррекции логирования TTL и независимости Momentum от Volume не изменили сигналы/ledger до этой причинной поправки; hashes и происхождение сохранены в provenance.

## C1 и неизвестные обязательства

C1 отдельно от reference-цен: один действующий tick на исполненную сторону/абстрактную ценовую единицу. USD 0,01; GLD 0,1; IMO 0,5; CNY 0,01 до **27.09.2023 19:00 MSK**, затем 0,001. Каждая сторона датируется отдельно. Gross − C1 = Net_model_C1 только при полностью определённых закрытии и необходимых расходах. Обычные комиссии, spread/slippage поверх C1 не добавлены; фактическое ГО не превращается в q=1.

**12** сохранённых модельных сделок имеют неразрешённые последствия: 7 — gap при известной открытой позиции, 4 — gap при возможном pending-entry перед acknowledgement, 1 — оба. Они модельно закрыты позже, но funding/emergency/неустановленные последствия остаются UNRESOLVED. **8 дополнительных неизвестных заявок** не имеют доказанного факта входа/выхода и не превращаются в model trades. Для них C1 также неизвестен, а не автоматически ноль: списание применяется только к исполненным сторонам. Полный годовой Net/PF учитывает обе категории неопределённости; закрытая часть не является полной доходностью стратегии.
