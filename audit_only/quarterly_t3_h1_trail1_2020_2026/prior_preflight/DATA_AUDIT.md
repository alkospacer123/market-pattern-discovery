## Семь обязательных вопросов

| Вопрос | Установленное состояние |
|---|---|
| Непрерывная история или отдельные контракты? | По форме — один multi-year OHLCV stream на рынок. Contract IDs отсутствуют. Его экономическая continuous-конструкция не установлена. |
| Правило перехода поставщика? | Не найдено; неизвестны supplier, выбор контракта, switch timestamps и основания выбора. |
| Корректировка цен? | Не установлены additive/multiplicative/unadjusted treatment, коэффициенты и point-in-time availability. |
| Искусственные roll gaps? | Невозможно классифицировать без roll map. Крупные наблюдаемые гэпы сохранены как диагностические доли, не объявлены roll-артефактами. |
| Причинность индикаторов/сопоставимость стопов после перехода? | Нельзя подтвердить для реальной истории без устройства серии и перевода открытой позиции/ценовых уровней. Синтетический causal audit проверяет только код. |
| Сессии и timezone? | Source timestamps naive. Frozen loader convention — Europe/Moscow/open+1h; подтверждения поставщика и исторического календаря нет. |
| Дубликаты/пропуски/Volume/OHLC? | QA выше; торговые пропуски остаются неопределёнными без календаря. |

Папочный README и шесть инструментальных README содержат только перевод строки. Их история состоит из создания пустых README. В доступном репозитории исследований найдена convention loader, но не паспорт квартальной склейки. Эти поиски не доказывают, что документации не существует у владельца источника; они описывают доступные свидетельства этого окружения.

## Наблюдаемые ценовые разрывы

`data_quality.json` содержит пять крупнейших `abs(Open/previous_Close-1)` на рынок с timestamp, без публикации исходных OHLC. Например, максимум Si около 20.03% на 02.03.2022, BR около 13.71% на 09.03.2026, NG около 14.76% на 02.02.2026. Это могут быть реальные рыночные разрывы; их причина не установлена. Они не вычтены, не сглажены и не использованы как основание исключить инструмент.

Много дробных OHLC, в том числе в Si/MIX. Без исторической price grid и описания выгрузки нельзя доказать тип корректировки по дробной части или округлить значения до произвольно выбранного шага. Byte authentication также не исключает hindsight price adjustments со стороны поставщика. Склейка с будущими коэффициентами может сохранять отдельные отношения, но причинность и R-инвариантность нельзя предполагать без метода и границ применения.

## Конкретные недостающие сведения

Для **каждого** Si/CNY/GD/MIX/BR/NG требуется паспорт, связанный с указанным SHA256: provider/export version; constituent IDs; contemporaneous roll selection rule и effective timestamps; price-adjustment mode/factors и их доступность во времени; timestamp label/timezone и календарь; представление открытых стопов/позиций и rollover cash flows. Если ряд действительно без склейки, нужно объяснение экономического смысла multi-year цены и контрактной идентичности.

Без этого нельзя завершить обязательный аудит серий и интерпретировать новые сделки как реальные сигналы квартальных контрактов. Данные не реконструируются из старых trade ledgers. Другая continuous series не подставляется незаметно. Основной blocker — metadata, **не отсутствие шести исходных CSV**. Дополнительные файлы за 16.09–19.10.2026 нужны только при расширении фактически доступного покрытия, а не для искусственного выполнения полной даты.
