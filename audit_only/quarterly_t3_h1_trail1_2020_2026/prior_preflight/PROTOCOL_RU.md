# Протокол независимого аудита

Версия 1, 19.10.2026. Зафиксированная база: `38489db7e69336548a583f968f13aab49c20913b`. Статус текущего этапа — `DATA_BLOCKED`, экономический вывод — `INCONCLUSIVE`. Этот код воспроизводит preflight и синтетические проверки; исторического backtester в этом PR нет.

## Область и последовательность

Проверяются Si, CNY, GD, MIX (PRIMARY) и BR, NG (ADDITIONAL). Состав неизменен. Запланированы агрегаты PRIMARY4, ADDITIONAL2, ALL6. Другие рынки не включаются. Интервал задания 01.01.2020–19.10.2026 ограничивается реально доступными завершёнными свечами каждого инструмента. Данные не дополняются, не сглаживаются, не пересклеиваются. Котировки остаются вне репозитория кода.

Последовательность: доступность и байтовая аутентификация → frozen authority → качество и roll-семантика → исторический replay → независимая сверка → годовые/периодические таблицы → N4/v2 → Draft PR → внешний аудит. Текущий этап остановлен на roll-семантике; последующие исторические этапы не отмечаются выполненными.

## Зафиксированная стратегия и издержки

Единственный candidate: `T3_H1_candidate_v3`, configuration `T3-H1-4e73cdb77246`, production identity `TRAIL1__N4_01__FULL__R15`. Параметры: EMA100, slope5, ADX14 >20, ATR14, ATR average20, prior Donchian20, initial stop2.5 ATR, trailing3 ATR, TRAIL1 trigger +1 frozen initial R. Для H4 используется существующая causal grouping из четырёх завершённых H1 в пределах локального дня. Это четыре наблюдения, а не новая resample-сетка по четырём часам. Пропуски и изменения сессий не исправляются.

Предусмотрена исходная SIGNAL_CLOSE семантика, отсутствие управления на entry bar, единственная активная позиция, без pyramiding. На событии сначала deferred activation и проверка входящего стопа, затем extrema/candidate; trigger-bar не исполняет новый trail. Стоп tighten-only; gap fill LONG=min(open,stop), SHORT=max(open,stop). EXIT до независимого ENTRY, без atomic reversal. Замороженные модули не редактируются.

PRIMARY C1: один normalized research tick `0.001` на сторону, два за круг. Для frozen initial risk `r=abs(entry-initial_stop)`:

`GrossR = sign * (exit-entry)/r`; `CostR = 0.002/r`; `NetR = GrossR-CostR`.

Это нормированная исследовательская стоимость. SECONDARY должен учитывать подтверждённые price steps, округление стопов, execution costs и rollover отдельно. При отсутствии исторических спецификаций SECONDARY и FULL/R15 cash-equity model не рассчитываются. В текущем этапе ни один исторический сценарий не выполнен.

## Методика будущих таблиц после снятия блокировки

Эти определения фиксируют план анализа; не являются описанием выполненного расчёта.

Год/месяц/квартал определяются **выходом сделки в Europe/Moscow**. Непрерывный quarterly replay не сбрасывает позиции/индикаторы на границах лет; открытая на конце данных позиция не закрывается принудительно, раскрывается отдельно и не попадает в закрытый NetR. При вынужденных независимых lifecycles это указывается явно.

Net PF = сумма положительных NetR / абсолютная сумма отрицательных NetR. Gross PF аналогично по GrossR. При отсутствии убыточной суммы PF неопределён/бесконечен с явным признаком, а не ноль. AverageR = сумма NetR / число закрытых сделок. Win% — доля NetR>0, нулевые сделки отдельно. Средние win/loss рассчитываются по соответствующим подмножествам NetR; средний loss отрицателен.

Closed-R curve сортируется по exit timestamp, затем instrument и trade ID, с начальной точкой 0. Max DD — минимальное значение `curve-running_max` (неположительное). Годовой DD рассчитывается внутри годового набора закрытий; это не сброс торгового состояния. Общий DD рассчитывается по полной хронологической сумме закрытых R. Совокупный PF вычисляется из всех сделок корзины, не усредняется из PF инструментов. Не взвешивается выдуманными лотами.

Устойчивость: ALL/LONG/SHORT, худшие год/квартал/месяц по NetR и явное покрытие неполных периодов, максимальная серия NetR<0 в фиксированном порядке, результат после удаления 1/3/5 крупнейших положительных NetR. Concentration share — доля этих сделок в сумме **положительных** NetR с раскрытием знаменателя. Число положительных/отрицательных лет определяется доступными непустыми периодами; неполные 2026 и CNY начальный год помечаются. Эти показатели ещё не вычислены.

## Сравнение N4

Источником может быть только аутентифицированный frozen TRAIL1 ledger Stage6/7. CANONICAL и Walk Forward не подмешиваются. Доступный физический Stage6 ledger проверен по manifest; строки Walk Forward исключены из множества возможных компараторов, но финансовая агрегация не выполнена.

Пары: Si/USDRUBF, CNY/CNYRUBF, GD/GLDRUBF, MIX/IMOEXF. Нужны индивидуальные результаты и общий PF четырёх, trade frequency, NetR и delta AverageR. Общие интервалы устанавливаются по пересечению реального покрытия и соответствующих frozen lifecycle windows, а не по первой/последней прибыльной сделке. Отсутствующие интервалы — `NO_COMMON_COVERAGE`; 2020–2022 N4 — `NO_DATA`. Частичная общая история 2023 не выдаётся за полный год. При lifecycle cold starts N4 сравнение должно явно раскрывать различие состояний и сопоставимости выборок.

Различия источников, единиц котировки, корректировок, liquidity и normalized C1 исключают утверждение, что разница вызвана только типом контракта. Больше PF не является достаточным критерием подтверждения математического ожидания.

## Независимость и воспроизводимость

`scalar_audit.py` имеет самостоятельные скалярные EMA/ATR/ADX/Donchian/H4, сигналы и lifecycle. Детерминированные синтетические fixtures сравниваются с frozen research authority и production replay, проверяются префиксы и изменение будущего. Есть adversarial trigger-bar и gap cases для обоих направлений. Синтетическая сверка не удостоверяет исторические сделки и склейку.

`preflight.py` читает оригинальный порядок CSV до sorting/deduplication, не пишет источник, сохраняет QA summaries и blank tables. `reproduce.py` запускает preflight дважды в свежих scratch directories, требует совпадения SHA256 каждого генерируемого файла, выполняет unittest и копирует отчётные артефакты только в текущий изолированный audit-каталог. Отсутствие metadata не снимается автоматически по результатам тестов.

```bash
PYTHONDONTWRITEBYTECODE=1 python audit_only/quarterly_t3_h1_trail1_2020_2026/reproduce.py \
  --data-root /workspace/market-pattern-data --scratch-root /workspace/work
```

Требуются Python3.12 и pandas2.2.3 (в окружении доступны); дополнительные зависимости для тестов не нужны. **Ожидаемый exit code — 2**, поскольку итог DATA_BLOCKED. При ошибке проверки выполнение завершается с ошибкой и не выдаёт завершённое исследование. `python test_preflight.py` отдельно должен вернуть 0.

`reproducibility.json` относится к генерируемым данным preflight, CSV-заглушкам и синтетическому аудиту. Статические Markdown и исходники не являются двумя историческими прогонами; их байты фиксирует commit PR, исходники дополнительно хешируются в `source_manifest.json`. Логи тестов содержат время выполнения и не являются детерминированными расчётными артефактами.

## Правила вердикта

Технические статусы: AUDIT_PASS только после полного выполненного и согласованного исторического аудита; AUDIT_FAIL при нарушении frozen identity/целостности/вычислений; DATA_BLOCKED при недоступных исходных данных или неустановленной обязательной семантике источника. Экономический вывод выбирается отдельно из SUPPORTED/MIXED/NOT_SUPPORTED/INCONCLUSIVE. Текущий выбор — DATA_BLOCKED/INCONCLUSIVE.

Никакие результаты не дают разрешения менять production. FINAM и торговые API не вызываются. После передачи Draft PR — STOP для внешнего аудита, без merge/auto-merge.
