# Замороженный протокол единственной проверки

Исследуется только **T1_NEXT_OPEN_TRAIL_3p5**. Производственный плановый ID — `T3_M15_T1_TRAIL35_N4_R15`; production не изменяется. Это заранее выбранная конфигурация, без оптимизации, поиска часов/лет/инструментов. Пользователь явно разрешил исторический описательный Gross replay 2020–2026, включая ранее исследованные периоды. Никакого нового TRUE OOS. Общие правила AGENTS.md о TRUE OOS и расходах не отменяют это конкретное разрешение пользователя; искусственная модель издержек не добавляется.

## Эталон и механика

Источники: `IntradayLab/SELECTED_T3_M15_SESSION_T1_R15.md`, `t3_m15_t1_entry_retest_v1/SPEC.json`, исполняемые `primary.py`/`verify.py`, frozen `t3_m15_execution_sensitivity_v1/`. Точные пути/SHA256 закреплены в `SOURCE_MANIFEST.json` на research main, полные файлы не изменены. Текущий preflight **не переосуществляет алгоритм стратегии**.

- M15 становится доступна после Close. H1 — группы по четыре в дневной ordinal-последовательности **даты Close**. Публикация при count=4 и last−first=45 минут; разорванные/неполные группы отбрасываются без перепаковки. Рекурсивные индикаторы продолжаются через даты и годы.
- EMA75: adjust=False EWM/min75; slope5. Wilder ATR14 и ADX14: adjust=False/min14. H1 ADX строго >20, H1 ATR14/rolling20 mean строго >1. LONG: H1 Close>EMA, slope>0; SHORT — обратные неравенства.
- M15 Donchian20 исключает текущую свечу, строгий Close-пробой. Входное окно по сигнальному Close `[10:00,18:00)` Europe/Moscow.
- Только NEXT_OPEN: Open следующей смежной M15; его timestamp равен сигнальному Close. Нет дополнительного ожидания 15 минут. Отсутствует смежная свеча — отмена pending, в конце unresolved pending не является позицией.
- Initial Stop = fill − side×2×ATR14 сигнальной M15; Initial R неизменен. Stop действует на execution candle. Не более одной позиции на инструмент, без пирамидинга.
- На каждом событии сначала действующий Stop; adverse gap исполняется по Open. После пережитой завершённой свечи накопленный благоприятный extreme − side×3.5×текущий ATR; только ужесточение. Новый Stop действует на следующей наблюдаемой свече. Нет +1R-триггера, безубытка или закрытия в 18:00.
- После выхода возможен новый независимый сигнал того же Close. Позиции/индикаторы не сбрасываются в январе. Открытые позиции на конце не ликвидируются принудительно.
- Frozen exit timestamp — **Close свечи выхода, включая Open-gap exits**. Годы/месяцы определяются по этому московскому timestamp; порядок метрик: exit_time/instrument/trade_id.

## Данные и экономика

Рынки обязательны: Si/CNY/GD/MIX = PRIMARY4; BR/NG = ADDITIONAL2; ALL6 — все. BR/NG не навязывается квартальная экспирация. Период запроса 01.01.2020–19.10.2026, отсечение по последней реально завершённой M15, а не по текущей дате автоматически. Ни одна свеча не изготавливается из H1/M30. Подлинные M1/M5 разрешены только при проверенной идентичности, корректной московской агрегации и явной обработке неполноты.

Первичный результат только GROSS_ONLY. Нормированный C1 H1 не переносится. R15 не превращает R в проценты капитала. Капитал, спецификации контрактов, ГО, расходы и rollover executions не выдумываются. Неизвестная склейка допускает описательный EXPLORATORY replay после проверки идентичности; real trading validation при этом отсутствует. Отсутствие паспорта склейки само по себе **не** причина текущей остановки.
