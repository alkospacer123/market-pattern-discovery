## Ближайшие действия

1. Не задерживать организацию TRL ради архива, который сейчас физически недоступен. V1–V24 с непроверенными оригиналами остаются `ARCHIVE_ONLY`, а не доказанными backtest-результатами.
2. Для первого реального исследования подтвердить **конкретные** исторические входные файлы, правила и повторный запуск существующего тестера в изолированном offline-контуре; при отсутствии оригинального ZIP — `BLOCKED_INPUT`.
3. Для ежемесячной аналитики V20 получить из отдельного LIVE-проекта безопасный готовый READONLY-снимок сделок и финансовых итогов. TRL не обращается в production SQLite и не запускает диагностические скрипты на рабочем хосте.
4. После подтверждения входного снимка пересмотреть `00.5`. Следующий регулярный обзор торговых идей запланирован на декабрь 2026.

**LIVE changes = 0.** Изменения текущей ветки — только документация под `TradingResearchLab/`; Draft PR не сливается автоматически.
