## Ближайшие действия

1. Рассмотреть оставшиеся существенные исключения 00.2: неподтверждённые оригиналы V1–V24, недостающие входные пакеты других тестеров, полноту/сессии/спецификации данных для будущих задач. Зафиксировать, какие ограничения принимаются как архивные, а какие блокируют конкретную работу. Непроверенные результаты остаются `ARCHIVE_ONLY`; заново повторять исследования ради архива не нужно.
2. Использовать проверенную связку `IntradayLab/t3_m15_forever_v1` + `market-pattern-data@f8486b4` + исходные BASELINE/OPTIMIZED + 2023–2024 + C1 как исторический технический контроль. Для новой гипотезы отдельно подтвердить её правила, входы, исполнение и расходы. Этот PASS не сертифицирует остальные тестеры, новую стратегию, V20 или независимый OOS; при отсутствии требуемого оригинального пакета — `BLOCKED_INPUT`.
3. Для ежемесячной аналитики V20 получить из отдельного LIVE-проекта безопасный готовый READONLY-снимок сделок и финансовых итогов. TRL не обращается в production SQLite и не запускает диагностические скрипты на рабочем хосте.
4. После подтверждения входного снимка пересмотреть `00.5`. Следующий регулярный обзор торговых идей запланирован на декабрь 2026.

**LIVE changes = 0.** Изменения текущей ветки — только документация под `TradingResearchLab/`; Draft PR не сливается автоматически.
