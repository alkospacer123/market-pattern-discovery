# TRL-R090 — распределение капитала V20: проверка доступных источников и условный тест
**Дата:** 19.11.2026 · **Решение:** `NO_REALLOCATION / FULL_BACKTEST_NOT_VERIFIED`

## Предмет
Финальная исследовательская сборка пользователя: `V20 60/30/45 + TP6 + Protect3 + HOLD5 без EXT2`. Общий банк 135 000 ₽. Рассматриваются семь альтернатив с теми же входами, риском 1,5%/сделка, 6%/счёт, NEXT_OPEN и первоначальным SL=2×ATR14 M15.

## Что содержат три полученных исходника
- **R086 XLSX:** агрегаты по годам, месяцам, срокам удержания и ГО для 2023–15.09.2026, но **отсутствует журнал построчных сделок и отклонённых сигналов**. Итоги R086 — **с EXT2**.
- **R087 XLSX:** шесть горизонтов, среди них HOLD5 64 построчные исполненные сделки (`Сделки C1`) за 16.09–17.11.2026 (одна позиция открыта 10.09). Только **с EXT2**, исходный банк 60/30/45; 64 сделки, +27 454,70 ₽, PF=2,34011.
- **R089 MD:** с EXT2 и без EXT2 сравнение только по агрегатам, без построчных сделок EXT2 OFF. Эталон без EXT2 на 2023–15.09.2026: 1 424 сделки, +459 798,1 ₽, PF=2,01559, M15 DD=20 049,4 ₽, ГО-отказов 241. На 16.09–17.11.2026: 69 сделок, +26 383,4 ₽, PF=2,17320.

**Следствие:** расчёт точного результата 2023–2026 для новых распределений без EXT2 невозможен только из этих файлов; построить из агрегатов новые сделки, ограничения ГО и последовательность портфельных P&L нельзя.

## Проверка восстановленной модели на исходных 64 сделках R087 (EXT2 ON)
По исходным сделкам можно извлечь первоначальный риск на один контракт: `net_C1 / net_R / lots`. Проверена условная симуляция лотности для 7 распределений: min(initial capital, realized balance), 1,5% риска на вход, 6% совокупного начального риска по открытым сделкам, фиксированное октябрьское ГО по N4, целые лоты, первоначальные времена входа и выхода, линейный P&L на контракт.

**Контроль воспроизводимости не пройден полностью:** исходная лотность совпала в **54 из 64** сделок при исходной модели; модель пересчитала +27 603,3 ₽ вместо оригинальных +27 454,7 ₽ (расхождение +148,6 ₽, +0,54%). Утраченное до 16.09 состояние счетов, не представленные отклонённые сигналы, действующие защитные стопы и точный порядок расчёта risk/GO не позволяют исправить это без исходного replay.

## Что показывает диагностика
- **75/30/30** лидирует по условной сумме на фиксированном списке R087, но пропускает 2 из 64 ранее исполненных сделок, имеет выше закрытую DD (8 811 ₽) и наиболее слабый Top5-стресс среди 60/30/45, 70/30/35 и 75/30/30.
- **60/30/45** более устойчив к исключению пяти лучших сделок в этом узком исследовании: +3 491 ₽ после Top5 против −930 ₽ у 75/30/30. Стресс не является новым P&L-путём.
- По исходному R089 без EXT2 в 2025 году PF=1,61035 — структурный риск слабого года остаётся важнее небольшого роста прибыли на 64 осенних сделках с EXT2.
- **Критическое ограничение:** выигрыш на выборке EXT2 ON не подтверждает прибыльность и устойчивость 75/30/30 без EXT2 в 2023–2026; ни PF, ни DD нельзя переносить между этими исследованиями.

## Решение
`HOLD / NO_REALLOCATION`. Сохранить 60/30/45 в качестве действующего исследовательского решения, варианты 70/30/35 и 75/30/30 как неопровергнутые кандидаты. Требуется восстановить полный R089 cash-replay или сигнал-доходность ledger со всеми отказами. Никаких LIVE-действий из TRL.
