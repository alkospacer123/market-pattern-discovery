# Trading Research Lab (TRL)

**Статус:** TRL-00 закрыт 31.10.2026; TRL-01 — ежемесячно с ноября 2026; TRL-02 — январь/апрель/июль/октябрь с 2027. **Назначение:** непрерывный, прикладной поиск торговых преимуществ и развитие работающих стратегий. Не универсальный автономный AI и не монитор.

## Три направления

- [Research](research/): ежемесячный обзор **новостей трейдинга и алготрейдинга**, новых торговых стратегий, научных исследований, профессиональных публикаций и форумов, технологий и инструментов, рыночных изменений и новых возможностей; оценка объяснимых гипотез, приоритетов и применимости к MOEX.
- [Evolution](evolution/): независимая аналитика реальных результатов V20 Shallow / OBV / Inside и будущих роботов; кандидаты на улучшения.
- [Journal](journal/): хронологические, append-only записи идей, проверок, ограничений и решений.
- [Reports](reports/): инвентаризация и месячные / квартальные / годовые сводки.

## Регламент

| Периодичность | Обязательное действие | Выход |
|---|---|---|
| **TRL-01 — ежемесячно** | Анализировать новости трейдинга/алготрейдинга, стратегии, научные и профессиональные материалы, технологии, новые возможности; разобрать V20 и портфель по предоставленным отчётам Финам | Месячный обзор Research + Evolution + Journal |
| **TRL-02 — январь, апрель, июль, октябрь, с 2027** | В назначенном месяце проверить минимум одну новую стратегию при достаточных данных; улучшение V20 — только при обосновании | Воспроизводимые эксперименты и решения |
| **Декабрь, начиная с 2027** | Предварительные финансовые итоги, качество исследований и план следующего года (финансовая сверка — в январе) | Годовой отчёт |
| При существенном результате | Зафиксировать наблюдение, тест или решение | Запись Journal |

### Исследовательский процесс

Источник идеи → объяснимый механизм прибыли → зафиксированные правила → проверка качества данных → исторический тест → устойчивость → независимая проверка с поправкой на многократное использование истории → решение **REJECT / CONTINUE / CANDIDATE**.

**Ограничения:** frozen V20 не изменять; результаты 2018–2026 не считать заведомо независимым OOS; расходы и допущения показывать явно. Текущая LIVE эксплуатация, FINAM, токены, заявки и production SQLite находятся вне TRL. Никакой исследовательский код не меняет действующие стратегии.
