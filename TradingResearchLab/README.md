# Trading Research Lab (TRL)

**Статус:** TRL-00 / организационный фундамент. **Назначение:** непрерывный, прикладной поиск торговых преимуществ и развитие работающих стратегий. Не универсальный автономный AI и не монитор.

## Три направления

- [Research](research/): новые торговые идеи, первоисточники, гипотезы, замороженные правила, тесты и решения.
- [Evolution](evolution/): независимая аналитика реальных результатов V20 Shallow / OBV / Inside и будущих роботов; кандидаты на улучшения.
- [Journal](journal/): хронологические, append-only записи идей, проверок, ограничений и решений.
- [Reports](reports/): инвентаризация и месячные / квартальные / годовые сводки.

## Регламент

| Периодичность | Обязательное действие | Выход |
|---|---|---|
| Ежемесячно | Изучить новые исследования и технологии; разобрать V20 READONLY и портфель; назначить приоритеты | Месячный отчёт и записи в Journal |
| Ежеквартально | Проверить минимум одну новую стратегию и один потенциальный апгрейд действующей, при достаточности данных | Воспроизводимые эксперименты, решение |
| Ежегодно | Финансовые итоги, качество исследований, решение по направлению развития | Годовой отчёт |
| При существенном результате | Зафиксировать наблюдение, тест или решение | Запись Journal |

### Исследовательский процесс

Источник идеи → объяснимый механизм прибыли → зафиксированные правила → проверка качества данных → исторический тест → устойчивость → независимая проверка с поправкой на многократное использование истории → решение **REJECT / CONTINUE / CANDIDATE**.

**Ограничения:** frozen V20 не изменять; результаты 2018–2026 не считать заведомо независимым OOS; расходы и допущения показывать явно. Текущая LIVE эксплуатация, FINAM, токены, заявки и production SQLite находятся вне TRL. Никакой исследовательский код не меняет действующие стратегии.
