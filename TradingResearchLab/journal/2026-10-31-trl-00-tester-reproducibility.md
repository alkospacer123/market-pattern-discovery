## Факты

- В существующей ветке `trl/00-inventory-20261031` и Draft PR [#569](https://github.com/alkospacer123/market-pattern-discovery/pull/569) проверен один существующий тестер `IntradayLab/t3_m15_forever_v1/research.py`; code SHA `9457da1f49578f940859a678d20b3c4f505bc394`.
- Использованы реальные M15 USDRUBF/CNYRUBF/GLDRUBF/IMOEXF за доступный 2023–2024 из `market-pattern-data@f8486b446cf3d5f9f3cba6dfec32bdef8fd184c8`, плюс 12 существующих квартальных M15 2023/2024 для сверки Si/CNY. Входы закреплены Git blob и SHA256, после запусков не изменились.
- Два свежих процесса в отдельном venv и внешнем рабочем каталоге, с запрещёнными сетевыми socket/connect, дали идентичные 17/17 артефактов и идентичный SHA256-инвентарь. Все они побайтово совпали с сохранённой публикацией тестера.
- BASELINE: 741 закрытая сделка, Net PF **1.350337**, Net **+117.168255 R**, Max DD **35.391174 R**. OPTIMIZED: 701 сделка, Net PF **1.444880**, Net **+152.537308 R**, Max DD **34.425955 R**. Это сумма закрытых R четырёх инструментов после модельных издержек C1, не доходность капитала; название OPTIMIZED относится к ранее замороженной конфигурации, новая оптимизация не проводилась.
- По одной позиции IMOEXF в каждой конфигурации остались открытыми; они исключены из закрытой статистики без выдуманного выхода.
- Существующий отдельный алгоритмический аудит подтвердил 1 442 закрытых сделки, 2 открытые позиции и 482 строки отчётов. Старые эталонные ledgers Si/CNY: 425 + 401 сделка, 0 расхождений в исходных допусках. 14 существующих unit/causality/execution tests прошли; они дополняют реальные исторические replay.
- OHLC 2025–2026 не разбирались и не использовались: временной парсер прекращает чтение до OHLC первой строки 2025+. Полный SHA256 файлов вычислен по непрозрачным байтам, включая более поздний суффикс. Новая OOS-валидация не проводилась.

## Решение и ограничения

**RUNTIME PASS / REPRODUCIBILITY PASS / REFERENCE PARITY PASS** только для указанной связки тестер + данные + исходные конфигурации + окружение. Её можно использовать как воспроизводимый исторический контроль для TRL в пределах существующей модели.

**TRL-00.2 остаётся PARTIAL / DOCUMENTED GAPS.** Не подтверждены оригиналы большинства V1–V24 и полные входные пакеты части других тестеров. Не сертифицированы все инструменты/периоды. Допущения signal-Close, C1, календарных ordinal-H1-блоков, неполной истории новых инструментов и незакрытых позиций сохранены. Реальная исполнимость, все финансовые обязательства и пригодность модели для V20 этим не доказаны. Алгоритмический аудит не заменяет внешнего reviewer.
