# TRL Journal — ручная финансовая выгрузка Финам

**ID:** TRL-J-2026-10-31-007  
**Дата решения:** 2026-10-31  
**Тип:** утверждённое организационное решение; TRL-01.2 (Evolution)

## Решение

Владелец TRL отверг автоматическую интеграцию как ненужную. Для регулярной оценки V20 основной финансовый вход — **ручная выгрузка отчётов Финам по трём независимым счетам** из личного кабинета; владелец прикладывает документы в чат TRL. Никаких новых PowerShell-экспортёров, API-синхронизации или TRL Monitor.

## Обоснование и границы

Ручное получение отчётов несложно для владельца; брокерский документ может дать фактические исполнения, комиссии и денежные операции, в зависимости от формы. Нужную структуру для первого отчёта проверить по реально полученным документам. TRL работает только с переданными копиями. Номера счетов и личные идентификаторы можно скрывать, сохраняя данные сделок и связь отчёта со стратегией (Shallow / OBV / Inside).

Брокерский отчёт **не гарантирует** первичный SL, причины сигнала, R, динамику equity и перекрытия роботов; эти показатели не выдумывать. Адресная техническая выгрузка из отдельного LIVE-проекта возможна лишь при возникновении обоснованной исследовательской потребности.

## Статус

Способ TRL-01.2 — **APPROVED**, фактическая выгрузка за ноябрь **PENDING**, расчёты — **HOLD_DATA** до получения. Технических изменений и действий в LIVE не требуется.
