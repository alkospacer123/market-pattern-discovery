## Проверено
- В Draft PR #569 уже присутствуют подробные ведомости 16 N4 `forever` CSV, 12 quarterly CSV, карта готовых тестеров и частичная реконструкция V1–V24.
- Поиск GitHub PR/commit с `V11`, `V23`, `V24` не открыл физически проверенные оригинальные исследовательские ZIP. Отсутствие результата GitHub search не доказывает отсутствия внешних архивов.
- В Draft PR #568 `ControlCenter/deployment/v20_live_export.py` и `cc/v20_contract.py` описывают `cc.v20.readonly.v1`: только состояния, циклы, события; без истории закрытых сделок/P&L.
- В Draft PR #567 имеется отдельная диагностическая read-only утилита с обращением к локальной SQLite. Использовать её из TRL не разрешается.

## Решение
1. Не восстанавливать V1–V24 путём бесконечного поиска без доступных оригиналов. Сохранять статус непроверенных ссылок; возвращаться к ним при поступлении архива или необходимости конкретной гипотезы.
2. **00.2 PARTIAL/DOCUMENTED GAPS**; это не блокирует оформление карточек и дневника, но блокирует использование недоказанных результатов для торговых решений.
3. **00.3 PASS** — создана компактная четырёхкаталожная структура без нового приложения.
4. **00.4 PASS** — шаблоны исследования, ежемесячного Evolution и месячного/квартального/годового отчётов.
5. **00.5 HOLD_INPUT** — для расчёта фактических PF, RUB, R и DD обязателен отдельный обезличенный торгово-финансовый READONLY-снимок; статусный экспорт Control Center недостаточен.
