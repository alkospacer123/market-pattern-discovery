# TRL — карточка гипотезы

> Создавать копию с отдельным ID `TRL-R-YYYY-NNN`. Не изменять первоначальную гипотезу после получения результата; новые версии и проверки — отдельные записи или дополнения с датой.

| Поле | Значение |
|---|---|
| ID / дата / исследователь | |

| Направление стратегии (если применимо) | TREND / MOMENTUM / VOLATILITY / OTHER; допустимо несколько классов, это не критерий приёмки |
| Причинная гипотеза и критерий её опровержения | |
| Источник идеи и URL, дата публикации | |
| Предполагаемый **механизм прибыли** | |
| Инструменты / TF / торговая сессия | |
| Точные правила сигнала, входа, выхода, SL / экспозиции | |
| Эталон для сравнения (если применим) | |
| Источник данных / путь / SHA256 / период / timezone / roll | |
| Разделение выборок (если применяется) / OOS-статус | |
| Уже использованные в исследовании периоды и число проверенных вариантов | |
| Исходный код / commit SHA / конфигурация | |
