# STS — Shallow Trend System

**11.11.2026 | RESEARCH ONLY | не утверждена для LIVE.**

STS — долгосрочное (5–20 лет) исследовательское направление TRL: одна фундаментальная идея **продолжения тренда**, меняющийся со временем набор причинно определённых модулей входа, **единый контроль позиций, капитала, ГО и риска**. Перечень модулей открыт: Classic, Micro, Flag, Sideways, Dynamic — лишь стартовый список, а не обязательная сборка или предел развития. Существующий frozen Shallow служит эталоном.

**Главный вопрос:** какая конфигурация обеспечивает наиболее устойчивую реальную прибыль при равном капитале/совокупном риске?

- **A:** действующий V20 Shallow + OBV + Inside;
- **B:** frozen Shallow TP6R + защита и весь общий капитал;
- **C:** единый модульный STS с добавлением/заменой прошедших доказательную проверку входов.

Допустимый итог исследования — **оставить A либо B**. До независимого подтверждения новые модули в LIVE не внедрять; OBV и Inside сохранять.
