Режимы:

- **check** — состояние трёх Tasks, тот же SID, точное LIVE action, состояние локального Kill Switch, последние 10 циклов, свежесть не более 90 секунд. Никаких вызовов FINAM и изменений. Если у робота нет подтверждённого здоровья, команда завершается FAIL, другие роботы не затрагиваются.
- **backup** — из текущих SQLite получить согласованные `sqlite3.backup()` снимки H1-совместимого V20 state плюс последние 100 строк журнала и снимок kill-switch каждого робота. - **stop** — не останавливает процесс, а переводит **только V20 Kill Switch в HALTED**. Новые входы запрещены; открытые позиции, SLTP и исходный третий сеанс продолжает сопровождать действующий исполнитель. Это безопасная операторская «пауза».
- **start** — запускает только зарегистрированный V20 Task (если остановлен), ждёт нового цикла и переводит собственный Kill Switch в ARMED **только при broker clean по FINAM** и уже проверенной локальной identity. Повторный start здорового ARMED — без изменений.
- **restart** — сначала readonly FINAM проверка нулевой позиции и нулевых активных заявок именно на выбранном счёте; затем HALT, остановка только соответствующего V20 Task, старт и broker-clean ARM. **При любой открытой позиции или SLTP RESTART запрещён.** Использовать только при конкретной неисправности, а не для периодического «оздоровления».
  
Параметр `-robot all` либо отдельный `v20-shallow`, `v20-obv`, `v20-inside`. Для работы с одним конкретным роботом остальные не меняются.
