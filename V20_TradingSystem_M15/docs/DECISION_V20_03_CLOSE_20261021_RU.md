# Решение владельца: закрыть V20-03 и перейти к V20-04

**Дата:** 21.10.2026. **Проект:** V20_TradingSystem_M15. **Roadmap:** строго 8 этапов (V20-01–V20-08).

## Принятое решение

**V20-03 — CLOSED / ACCEPTED WITH LIMITATIONS.** Владелец принимает историческое исследование и диагностику падения PF как достаточную для перехода к offline-разработке. Исторический вычислительный статус V20-03 **PARTIAL**, а не безусловный PASS по полному N4 и сопоставимости. Сохраняются отсутствие старого GLD, ограниченный CNY, 12 censored, контракт/календарь/selection-bias и неполная ценовая/live-экономика. Сохраняются оригинальные acceptance и frozen research-артефакты без переписывания.

**V20-04 — START / IN PROGRESS, OFFLINE ONLY.** Разработать **все три** независимые конфигурации на одном общем исполнительном каркасе, переиспользующем проверенные решения H1 и M15:
1. V20-Shallow — Shallow Pullback.
2. V20-OBV — OBV Pressure.
3. V20-Inside — Inside Day Release.

Рекомендация аналитиков V20-03 «Shallow первый, Inside второй, OBV HOLD» сохранена как историческая оценка разной надёжности; **владелец отдельно разрешил разработку OBV**. OBV не получает автоматического разрешения на LIVE, как и остальные.

## Замороженные параметры

- N4: USDRUBF, CNYRUBF, GLDRUBF, IMOEXF; M15; только завершённые свечи; NEXT_OPEN.
- Точные frozen сигналы V20/V4; первоначальный stop 2×ATR14 Wilder, округление наружу по исполнимой сетке; выход по stop или исходному правилу до третьей наблюдаемой сессии. Не менять/не оптимизировать стратегии из-за старого PF.
- Отдельный счёт FINAM, токен, процесс, Task, состояние/позиции/заявки/защита/журналы для каждого робота. Сигналы разных счетов не блокируют друг друга; внутри робота не более 2 входов за сессию, не более 1 нового входа на инструмент за сессию и 1 открытой позиции на инструмент.
- План 3×500 000 ₽; начальный ориентир риска 1,5% на сделку **не утверждён для LIVE**. Реальные ГО/тики/комиссии/проскальзывание/совокупная экспозиция и целые контракты обязательно проверяются до LIVE.
- Переиспользовать H1 FINAM order/SLTP, tick-grid и sizing после PR #493, recover/reconcile/kill-switch/идемпотентность и Windows operator scripts; из M15 — completed bars, session/NEXT_OPEN. **H1 и M15 не модифицировать**, не переписывать работающий исполнительный механизм.

## Последующие этапы и полномочия

- V20-05: offline приёмка всех трёх (signals, stops, money, independent processes, failure/recovery).
- V20-06: FINAM READONLY трёх V20-счетов без заявок.
- V20-07: установка на Intel, LIVE off; изолированные Disabled Tasks.
- V20-08: отдельная разрешённая пользователем реальная проба и **отдельное разрешение для каждого LIVE**. Решение от 21.10.2026 **не разрешает реальные торговые операции, активацию, чтение/использование производственных токенов, изменения работающего H1 или Windows Tasks**.
