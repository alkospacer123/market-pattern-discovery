# V20-03: заранее зафиксированная единственная политика V1

Зафиксирована 21.10.2026 до первого stress replay. Исходный проект/сигналы не редактируются. Это исследование доступного состава, все PF CONDITIONAL, итоговый статус PARTIAL/HOLD.

1. Часы CSV условно MSK, timestamp условно начало M15. Точно сохраняем якорь V20-02: session = normalize(timestamp − 9h), включая отнесение 07:00–08:45 к предыдущему ключу. Сигнал известен open+15min. Shallow/OBV: исходные 10:00–17:00; Inside: 10:00–16:45. NEXT_OPEN только ровно +15min, тот же контракт.
2. В 09:00 ключа наблюдаемой сессии выбирается ближайший по сроку квартальный контракт, имевший в предыдущей наблюдаемой сессии базового инструмента завершённую дневную историю: ≥12 баров 10:00–17:45, первый ≤10:15, последний ≥17:15. Кандидаты только уже наблюдавшиеся, данные текущей сессии/будущие объёмы/будущий последний timestamp не участвуют. При равенстве — имя файла. Сроки монотонны, назад не возвращаемся. Отсутствие кандидата означает отсутствие входов, без подстановки.
3. Запрет новых входов в старый контракт с понедельника недели его номинальной экспирации (третий четверг квартального месяца). Дата вычисляется по имени, не по будущему концу CSV; исторические исключения календаря не подтверждены, поэтому календарь условный. Ни ликвидность, ни доходность для оптимизации выбора не используются. Старую позицию ведём тем же stop/time правилом, новый контракт ждёт её закрытия. Pending не переносится на другую серию. Лимит один символ/сессия сохраняется через ролл, максимум 2 входа на каждый из трёх независимых счетов.
4. Индикаторы считаются отдельно для каждого контракта исходными функциями. Никаких поправок цены, склеек, интерполяции или переноса EMA/ATR. Внутри серии после неподтверждённого разрыва M15 в одном ключе сессии начинается новый независимый сегмент. Разрыв определяется при появлении следующей свечи. Допустимые перерывы: переход между ключами сессий; 18:30→19:00/19:15; 13:45→14:15. Последние два допуска только в пределах одной календарной даты и условны без полного календаря остановок. Обычный overnight остаётся как в эталоне. Прогрев исходных EMA200/ATR не сокращается. Повреждённая OHLC/объём/датировка/тик-сетка прекращают обработку, без исправления.
5. Позиция, пережившая такой разрыв или пропуск наблюдаемой сессии базового инструмента, остаётся в машине состояний до обычного выхода, но целиком исключается из основной статистики как CENSORED_DATA_GAP. Она продолжает занимать символ и лимиты, не заменяется выгодной ценой. Все такие сделки видны отдельно вместе с условным наблюдаемым выходом. Конец архива/серии не порождает искусственный close: открытые позиции имеют неизвестный результат и отдельный реестр. Период до прогрева, отсутствие кандидата, несовпадение смежности и окна сигналов доступны в audit-таблицах. Это консервативная проверка наблюдаемости, не новый фильтр стратегии; она меняет доступную выборку и может смещать PF.
6. Реальная сетка в единицах CSV: Si=1; MIX=25; CNY=0.01 до 2022-10-06 19:00 и 0.001 после. Смена CNY объявлена MOEX 29.09.2022, не выведена из прибыли. Стоп 2×ATR14 Wilder с исходным ewm seed, округление наружу по сетке в момент входа, stop-first, выход на открытии третьей наблюдаемой сессии. При смене сетки неизменный старый стоп остаётся допустимым на более мелкой сетке.
7. Расходы без вымышленных комиссий: C1=1 текущий тик на каждую сторону, C2=2, STRICT=4. cost_R = k×(tick_entry+tick_exit)/risk; исполнение цены и размер стопа общие для всех сценариев. Не рублёвая доходность, не фактические тарифы; отдельно сохраняется стоимость тика как свидетельство спецификации. Порядок одновременных событий как V20-02: CNY, MIX, Si (GLD отсутствует), затем срок/имя.
8. DD — просадка последовательности закрытых R с начальной вершиной 0; сделки сортируются по времени выхода, далее времени входа, счёту и контракту. Не внутрисделочная/денежная/маржинальная DD. Общая сумма трёх счетов — арифметическая диагностическая сводка, не один исполняемый счёт. Год/месяц по выходу; пустые периоды отмечаются без PF.

Принят только один вариант. Ни после просмотра PF, ни для 2019/2022 политика не подбирается. Для Si-9.19 односуточная серия может быть выбрана по прошлому дню, но её 55 баров не дают прогрева EMA200. На следующей сессии без её подтверждения допускается уже наблюдавшаяся Si-12.19 по тем же правилам; прошлые свечи Si-12.19 не выдаются за Si-9.19.
