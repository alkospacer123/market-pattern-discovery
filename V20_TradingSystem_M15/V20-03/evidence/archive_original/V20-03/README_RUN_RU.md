# Воспроизводимый V20-03 — только offline

Итоговый статус PARTIAL/HOLD. Все PF условны, это не полный N4 и не новый OOS. Распакуйте поставку и перейдите в `V20_TradingSystem_M15`. Команды ниже ничего не отправляют в сеть, не обращаются к брокеру и не изменяют замороженные исходники. `work` используется только для повторного результата.

Нужны Python 3.11+ и зависимости из `offline/requirements.txt`: numpy 2.3.5, pandas 2.2.3. При их отсутствии установите заранее из доверенного wheel-кэша. Для самого запуска сеть не нужна. Numba не требуется: точные AST-тела исходных функций вызываются без их устаревшего top-level bootstrap; все формулы и параметры сохраняются, сверены с V20-02. Не запускайте напрямую старые `run.py`/`study_v4.py`: их main пишет старые отчёты и использует старые абсолютные пути.

```bash
sha256sum -c DELIVERY_MANIFEST_SHA256.txt
python V20-03/offline/test_causality.py --out work/CAUSALITY.json
python V20-03/offline/stress_v20_03.py --out work/repeat
python V20-03/offline/verify_repeat.py V20-03/results work/repeat --out work/REPEAT.json
```

Все четыре команды должны завершиться с кодом 0. Сравниваются все байты всех файлов результата, включая исходные хеши/версию Python. Для побайтового совпадения `RUN_METADATA.json` версия Python должна совпадать с `results/RUN_METADATA.json`; изменение версии не разрешает игнорировать отличия торговых таблиц. Файлы результатов не включают время запуска и абсолютный путь вывода, поэтому два запуска в одной зафиксированной среде должны совпасть полностью.

`verification/CAUSALITY.json` — журнал выполненных проверок исходников, всех трёх сигналов, принятого replay 1589 сделок, удаления будущего в 43 контрактах, ролла и выполнения ордеров. Данные принятых V20-02 за 2023–2026 используются только в проверке неизменности эталона, не для настройки/селекции V20-03; собственно стресс-запуск читает только оригинальные серии 2017 (прогрев MIX)–2022, новые входы только 2018–2022.

`MANIFEST_SHA256.txt` сохранён как полученный документ: он описывает исходную поставку, а три обновлённых файла V20-03 по нему закономерно отличаются. Для текущей поставки используйте `DELIVERY_MANIFEST_SHA256.txt`. Подлинные исходные версии этих трёх документов и исходный внешний ZIP находятся в `V20-03/original_received/`.

Таблицы `CLOSED_TRADES.csv`/`STATISTICS.csv` содержат основную условную выборку; `ALL_OBSERVED_CLOSED.csv` и `CENSORED_CLOSED.csv` позволяют проверить исключённые сделки. `OPEN_POSITIONS.csv` при отсутствии позиций пуст; это не результат искусственного закрытия. Пустые статистические периоды имеют 0 сделок и пустые PF/R/DD, не фиктивную доходность. C1/C2/STRICT — стоимость 1/2/4 тиков на сторону, не фактическая комиссия.

После генерации нового кода или изменения входов исходное совпадение более не гарантируется. Политика `ROLL_POLICY_LOCKED_V1.md` зафиксирована до просмотра результатов; текущая реализация использует только её, без перебора вариантов.
