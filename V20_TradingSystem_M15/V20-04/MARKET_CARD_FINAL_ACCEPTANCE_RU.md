## Что доступно заранее: один неизменный анализ

Единый `evaluate_market_card` не менялся. Пять групп: продолжение пробоя, возврат за уровень, ER, CLV×Volume×направление, Inside (сжатие + завершённый выход). ATR/Close справочно. Breakout/Inside continuation — подтверждение следующим завершённым M15 в той же сессии; возврат — закрытие следующего M15 за прошлым уровнем. Это короткие рыночные прокси, не точная копия трёхсессионной выживаемости позиции.

Повторно использованы LOCKED_V1 selection/gap/progрев и **1088 / 579** дневных 20-сессионных снимков. Сигнал получает только предыдущий завершённый снимок той же серии; неполный день не выкидывается из окна, roll не склеивается. Исход самой оцениваемой сделки не входит в признаки. Полный горизонт используется лишь как будущая метка; прошлые исходы для дополнительной характеристики доступны только после их полного завершения.

Создание именно показанного входа (внешний каталог, без чтения 2025/2026), затем штатный CLI:

```python
from pathlib import Path
from datetime import datetime
from dataclasses import asdict
import json
from V20_TradingSystem_M15.v20_runtime.market_epochs import read_bars, series
with Path("<external/forever>/USDRUBF/USDRUBF_M15.csv").open(encoding="utf-8-sig") as f:
    bars = read_bars(f, years={2023, 2024})
source = series([b for b in bars if b.open_time <= datetime(2024, 11, 2, 17, 45)])
sessions = [source["sessions"][d] for d in sorted(source["sessions"])[-20:]]
data = dict(symbol="USDRUBF", as_of_msk="2026-10-22T15:00:00",
    completed_sessions=[asdict(s) for s in sessions], expected_session_days=[s.day for s in sessions])
Path("<external>/snapshot.json").write_text(json.dumps(data, default=lambda x: x.isoformat()))
```
