# V20-04.2 — квартальная/полугодовая пригодность и крупные движения, 2018–2026

**Защита капитала через исключение: FAIL. Расчёт/адресные проверки: PASS. Для READONLY-наблюдения выбран QUARTER_3M_6M, без торгового запрета.**

Проверка не подтвердила безопасный способ временно исключать инструменты после слабого квартала или полугодия. Полугодовое подтверждение уменьшает число ложных решений, но пропускает существенные восстановления и не улучшает просадку обоих активных счетов. Квартальная схема немного помогает слабым 2019–2022 ценой гораздо большей потери прибыли хороших эпох. Никакого дальнейшего подбора окон/минимумов/стратегий не проводилось.

Фактический main `6f352acfac7ebdfabba73e143c4dfea3a6e48507`; input head PR #567 `669bad64e8633bdbbcee3b500330b7a2b6c7fdc5`. Итоговый SHA — коммит с данным отчётом, указан в PR и итоговом сообщении. PR остаётся Draft, без Merge/LIVE. Только существующий V20-04.2, roadmap 8 этапов / 24 подэтапа.

## Протокол и смысл показателей

[Правила зафиксированы до результатов](V20_CALENDAR_REVIEW_PROTOCOL_RU.md): ровно три схемы владельца, минимумы **10 сделок / 3 месяца, 20 / 6 месяцев**, знак net C1 относительно 0R. Никаких новых индикаторов, подбора PF или изменения торговых параметров. История уже использована, независимым OOS не является. 2025/2026 разрешены локальным AGENTS.md V20.

Время — MSK naive. Пересмотр в 00:00 первого дня квартала/полугодия; окно завершений `(T−3м,T]` / `(T−6м,T]`. Стоп по High/Low доступен только после закрытия M15, Open-выход — сразу. Граница ровно T входит в завершившийся период; месячные/годовые таблицы используют то же правило. Решение действует с первой наблюдаемой сессии инструмента, без использования её будущих OHLC. Статистика исключённого инструмента продолжает читаться из неизменённого базового журнала, это исследовательская сверка, не новый сервис.

3м/6м исключения истекают при следующем пересмотре: недостаточность даёт INSUFFICIENT без нового запрета. У 3+6 уже начатое исключение сохраняется до достаточного положительного квартала; если N мало, **assessment=INSUFFICIENT отдельно от carried_exclusion=True**. Этот заранее объявленный вариант тоже оказался дорогим. Неопределённость не выдаётся за хороший рынок.

**Три разных оси данных:** (1) решение по известным завершениям; (2) цена запрета по новым входам после effective_at, с учётом реального условного replay; (3) raw-пути по дате сигнала и модельные сделки дополнения по дате входа. Полная квартальная траектория может завершиться уже в следующем квартале: для причинной оценки сохранены отдельные `known_at_review_*`, содержащие только известные на дату проверки исходы. Будущие результаты находятся в `next_q_*`, `second_q_*`, `next_h_*` и никогда не формируют прошлое решение.

Следующий квартал считается FALSE при положительном net C1, USEFUL при отрицательном, **только если он полностью доступен, N>=10 и нет неизвестных результатов**. Иначе UNRESOLVED, включая неполный 2026Q3. Для следующего полугодия минимум 20. Pending-позиции могут закрыться в следующем квартале, но их результат не считается предотвратимым новым запретом.

Нулевая задержка означает, что запрет сохранялся и на первой доступной сессии слабого квартала, не предсказание начала слабости.

## Дополнение: крупные движения до стопа

FP2/3/5 и MFE_low/high взяты из прежних 3990 событий. FP4 выведен из тех же стоп-обрезанных границ: нижняя достигла 4R — доказанное достижение; только верхняя — неоднозначность, консервативно стоп раньше цели. Строго >5R отличается от касания 5R. Для FP2/FP3/FP4/FP5 и строго >5 во всех 3990 наблюдаемых уникальных событиях неоднозначных крупных достижений **0**; консервативный и оптимистический подсчёты этих целей совпадают. Границы MFE всё же немного различаются из-за неизвестного порядка внутри стоповой свечи. Никакого сканирования всех ценовых путей заново: проверено, что тот же расчёт по MFE воспроизводит все опубликованные FP2/3/5. Вход/риск/горизонт не менялись, High/Low свечи после исходного Open-выхода не используются.

**FP5 не равен выигрышу +5R сделки.** Сигнал мог достичь уровня и затем вернуться; фактический frozen выход/C1 другой. Реальные модельные net>=4/5 показаны отдельно. MFE дан консервативной нижней границей и верхней чувствительностью; исходы неизвестного порядка не выдуманы.

### Пропуски данных и чувствительность

Наблюдаемость raw неодинакова: 2018 — 312/313, 2019–2022 — 1247/1297, поздний период — 2431/2865. Среднее MFE неизвестных путей не подставлено нулём. Для FP в CSV есть границы по всем raw при предположении, что все неизвестные — неуспех/успех, плюс неопределённый порядок.

Для 2018 против 2019–2022 интервалы перекрываются, поэтому частоты complete-case не дают строгого причинного доказательства исчезновения больших движений во всём рынке. Современный FP5 выше даже при грубой этой чувствительности, но состав инструментов/контрактов и обработка разрывов отличаются. Модельная алгебра выигрышей/убытков объясняет PF журнала; перенос её в универсальное объяснение рынка ограничен.

На полностью сопоставимых 19 случаях **10 причинно доступных сочетаний** «FP4↓/FP5↓/stops↑», из них **8 сопровождались прибыльным следующим кварталом**. Это не независимый прогнозный тест, но прямой контрпример безопасному исключению по этим завершённым характеристикам. Для описательного полного signal-cohort без отсечки на T было 9 сочетаний/8 восстановлений прибыли; эта версия отдельно сохранена и не выдаётся за причинный вход карточки. После роста стопов частота в следующем квартале нередко снижалась; все случаи сохраняются, а не выбираются только удачные.

## Рекомендация и минимальная READONLY-сверка

**Исключения инструментов не внедрять.** Из ограничителей HALF_YEAR_6M относительно остальных сохранил больше net R и дал меньше FALSE, но проиграл baseline на слабой эпохе и увеличил DD Shallow/OBV. Это не пригодный универсальный механизм защиты капитала. Высокий PF сам по себе не победа.

Для информационной карточки выбрать **QUARTER_3M_6M без применения action EXCLUDE**: рядом 3м и 6м, N/PF/net, дата завершённого пересмотра; короткая слабость при длинной положительной истории — предупреждение оператору, а не автоматическое исключение. При нехватке N — INSUFFICIENT. Последний полностью доступный пересмотр современного архива — 01.07.2026; никакой фиктивной сверки 01.10.
