**Интерпретация:** падение 2018→2019 в значительной мере связано не с ростом стопов (73.7→74.7%), а с исчезновением редких крупных продолжений, особенно на Si. В 2018 Si 10.6% незастопленных уникальных исходов имели horizon_R ≥10R, в 2019 — 1.5%. У MIX такого сильного перехода нет; нельзя объявлять универсальный для всех инструментов режим только по общей годовой цифре. У 2023–2026 профиль иных инструментов/контрактов, прямой перенос не доказан.

Условный \`stop_aware_reference_R\` = \`-1R\` при horizon stop touch, иначе \`horizon_R\`, **не реальный PnL**: без расходов, гэпа, проскальзывания и проверки истинного исполнения. Это отдельное справочное поле карточки, не критерий допуска.

## Проверена способность прогнозировать ПОЛОСУ будущих 40 исходов — НЕ ПОДТВЕРЖДЕНА

Для **1 712 исторических as-of моментов**, когда уже известны два прошлых окна по 20 уникальных исходов и имеются следующие 40 завершённых исходов (будущее используется только для ретроспективной оценки; не для решения на T):

- Доля отрицательного среднего stop-aware reference на следующих 40: **28.7%** по всем 1 712.
- Когда последние 20 stop-aware были отрицательными: **33.8%**.
- Когда stop-aware последних 20 уменьшалось относительно предыдущих: **24.8%**.
- Результат неодинаков между эпохами; в 2025–2026 сигнал «последние 20 отрицательные» не служил устойчивым предиктором следующего падения.

Предыдущая ретроспектива старой карточки: 151 эпизод, 64/140 (45.7%) полных будущих восстановлений. Объединённые уникальные 20/20: 114 эпизодов, 39/109 (35.8%) полных восстановлений. Если ждать пяти последовательных отрицательных сравнений, будет 78 эпизодов, 15/75 (20.0%) полных восстановлений, **но это не доказанная точность**: правило просмотрено на той же истории, точки последовательных сравнений перекрываются, сигналы запаздывают, эпизоды разные. У 2019 MIX первое снижение с объединением видно 22 января, после 5 подтверждений — 15 февраля.

Сравнение простых дополнительных условий на 80 известных событиях (прошлые 40 против предыдущих 40; stop-aware / доля ≥5R) **не доказало стабильного улучшения**: полный последующий возврат оставался примерно 41–52% в изученных сочетаниях. Это не параметры для добавления ещё одного «фильтра».

**Вердикт надёжности: FAIL для прогноза дальнейшей слабости рынка.** Экономическая ценность карточки как наблюдения уже случившейся смены поведения есть, но 20 событий недостаточно для устойчивой оценки редких 5–10R исходов. Надёжные минимальные/рекомендуемые thresholds и автоматическая пригодность по инструменту по-прежнему **НЕ УСТАНОВЛЕНЫ**. 2018–2026 использованы для исследования и не могут называться независимым OOS.

## Реализовано в этом PR

- \`v20_runtime/instrument_regime.py\`: один уникальный поток по инструменту, строго законченные горизонты, текущие/предыдущие 20, stop-aware и ≥5R для объяснения, наблюдаемая последовательность 5 снижений, давность/прогрев, статус UNKNOWN при нехватке или старости. Не объявляет future prediction validated, FINAM LIVE явно NOT_CONNECTED.
- \`v20_runtime/market_suitability_cli.py --symbol\`: одна карточка по умолчанию вместо трёх отдельных строк. Старые артефакты/метрики остаются доступны для диагностики; прежний \`--input\` путь не переделан.
- \`v20_runtime/tests/test_instrument_regime.py\`: 7 сфокусированных synthetic тестов (локально действительно выполнены 7 PASS, 0 FAIL, 0 SKIP), включающие overlap, конфликт, нулевой lookahead, атомарные горизонты, gap/freshness, stop-aware. 110 тестов прежней версии не приписывать новому SHA — полный suite после изменения **NOT RUN**.
- Торговые H1/M15/FINAM, frozen signal/stop/risk, N4, задачи Windows и токены не менялись. LIVE OFF.
