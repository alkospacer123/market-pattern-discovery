# Утверждённое решение владельца — минимализм универсальной карточки
Дата: 22.10.2026. Статус: УТВЕРЖДЕНО. Область: V20-04.2, проверки внутри V20-05.1; без нового этапа roadmap.

## Задача
Универсальная **независимая от роботов** карточка показывает пригодность любого выбранного фьючерса для каждого из трёх frozen-сигналов V20-Shallow, V20-OBV, V20-Inside. Пользователь самостоятельно решает, какие инструменты дать роботам. Карточка не меняет frozen N4, торговые параметры, сигналы, заявки, риск и стопы, не включает и не выключает автоматическую торговлю.

## Обязательный, но компактный минимум
Пять *аспектов* режима, а **не пять обязательных условий AND**:
1. Нормированная волатильность — достаточность ценового движения.
2. Направленность против шума — наличие устойчивого движения.
3. Продолжение / откат после пробоя — способность развивать направленный импульс.
4. Объёмное давление и согласованность с движением — исходный V20 CLV×Volume, не просто объём зелёных/красных свечей; особенно для OBV.
5. Сжатие диапазона / Inside — строгая вложенность завершённых сессий, выход из сжатия; особенно для Inside.

Сверять благоприятную среду с исходными 2023–2026 и контрастом 2018–2022, включая V20-03 **raw horizon** Shallow +0,406R против +0,953R, OBV +0,226R против +0,695R, Inside +0,205R против +0,733R. Эти значения — среднее движение к горизонту raw-сигнала, **не** средний торговый PnL и **не** входной признак текущей карточки.

## Вид карточки и вердикт
На первом экране: инструмент, дата/сессия, **три независимые оценки** Shallow / OBV / Inside и **одна–две понятные причины** каждой. Подробные числа — только по запросу, без перегрузки.

- **ДОПУСТИМО** — подтверждённое соответствие режиму, благоприятному для данной стратегии.
- **НЕЙТРАЛЬНО** — данные достаточны, но условия смешанные/пограничные; единственный слабый показатель не исключает инструмент.
- **НЕДОПУСТИМО** — только убедительные, проверенные признаки действительно неблагоприятного режима, не слабость отдельного индикатора.
- **НЕ ОЦЕНЕНО** — недостаточно подтверждений для правил классификации; **НЕДОСТАТОЧНО ДАННЫХ** — ненадёжные/неполные исходные свечи. Это не дополнительные рыночные статусы и не синоним «нейтрально».

**Не превращать пять показателей в пять жёстких фильтров.** Не добавлять сложные скоринговые модели, веса, сетки порогов, перебор гипотез, новые зависимости/службы и автоматическое исключение потенциально подходящих инструментов. Не подгонять под PF известной истории. Приоритет — практический отбор потенциально подходящих рынков с минимальным риском ложного отказа.

Качество данных и исполнимость/ликвидность — отдельные проверки достоверности, не дополнительные параметры оптимизации. Три статуса выдавать только после проверенной причинной исторической связи; иначе `НЕ ОЦЕНЕНО`.
