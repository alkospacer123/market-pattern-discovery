`horizon_R = side × (Open третьей наблюдаемой сессии − NEXT_OPEN entry) / initial risk`. Risk — исходный округлённый 2×ATR-стоп. Это подписанное движение цены к исходному сроку, **не PnL**: нет вычета расходов, позиция может давно закрыться по стопу. Третья сессия означает индекс сессии входа +2; срок не заменялся тремя календарными днями.

Причины непроверенных горизонтов: `UNKNOWN_INTRASESSION_GAP` — 550, `END_OF_ARCHIVE` — 3, `NO_NEXT_OPEN` — 2. Они исключены из среднего, а не заменены нулём.

Raw-сигналы и их горизонты перекрываются; повторения одной сессии не являются независимыми испытаниями. Старые Si/MIX — экономические прокси USD/индекса, не те же контракты N4; у старого набора нет GLDRUBF. Контрактная идентичность/роллы условны по V20-03. 2026 заканчивается в августе/сентябре.

## Что исправлено в общем расчёте

1. **Волатильность:** Wilder14 `adjust=False`, инициализация первым TR как в frozen `base.prepare`, вывод ATR/Close и медианы диапазонов сессии. Состояние начинается на границе 20-сессионного окна; это не исходный ATR-сигнал из всей истории.
2. **Направленность:** ER закрытий завершённых сессий; отдельно от ATR.
3. **Пробои:** закрытие за экстремумом предыдущих 20 баров и следующий завершённый соседний M15 той же сессии. Раздельно продолжение и возврат внутрь уровня; последний неподтверждённый бар не становится успешным пробоем. Это общая диагностика, не переписанный Shallow/OBV-сигнал.
4. **Давление:** точный `sum(CLV×Volume)/sum(Volume)` за 12 предшествующих баров, без текущего. CLV нулевого диапазона = 0, объём doji учитывается, нулевой суммарный объём = неизвестно. Окно явно пересекает завершённые сессии как frozen run.py. Сохранены знак/сила, согласованность с движением тех же 12 предыдущих закрытий, знаменатели; сильное давление против движения не превращается в благоприятное через abs.
5. **Сжатие/Inside:** дневные границы 10:00–17:45; V4-validity (`n>=12`, первый бар <=10:15, последний >=17:15) и строгие `<` / `>` двух завершённых диапазонов. Отдельно ratio диапазонов, доля строгих Inside, текущая завершённая пара и качество уже наблюдавшихся выходов. Пара фиксируется до дня пробоя. Для исторических release-crosses используются метки 10:00–16:45, без EMA-гейта frozen-сигнала; подтверждение — следующий соседний завершённый бар. Это диагностика, сами raw Inside-сигналы берутся из V20-03.

По умолчанию CLI показывает инструмент/дату, три оценки и до двух причин; численные подробности — `--details` или явный `--format json`. Все три readout JSON содержат пять групп. Inside дополнительно показывает качество release; ликвидность, lot/spread/ГО/издержки и достоверность календаря остаются отдельными проверками. Неизвестные поля показываются `НЕИЗВЕСТНО`.

`market_reference_descriptive.py` теперь вызывает общий расчёт карточки. Неполные наблюдаемые дни остаются в окне и делают его недостаточным; они больше не выкидываются с подменой на более старые полные дни. 20 — информационное окно, не подобранный торговый параметр.

CLI принимает `expected_session_days` из внешне проверенного календаря и ловит целиком пропущенную сессию. Без списка он явно сообщает `CALLER_ASSERTS_NO_OMITTED_SESSIONS`: отсутствие целого дня нельзя доказать одними свечами. Для истории здесь доступны лишь наблюдаемые даты, не подтверждённый FINAM-календарь.

Схемы карточки/профиля подняты до v2; прежние proxy-профили v1 и сравнение дельт с прежней методикой отвергаются. Пять групп — аспекты диагностики, а не пять обязательных условий AND. Сохранён компактный интерфейс двух релевантных признаков профиля на стратегию: ER/пробой для Shallow, согласованность давления/пробой для OBV, сжатие/release-quality для Inside. Единичный неблагоприятный показатель даёт `НЕЙТРАЛЬНО`, `НЕДОПУСТИМО` требует совместного подтверждения обоих в независимо проверенном профиле. Это защитная логика интерфейса; реального доказанного профиля пока нет. Предъявленный JSON PASS по-прежнему требует независимой проверки артефакта оператором.

## Связь с последующим движением

Spearman(feature, horizon_R), слева 2023–2024 / справа 2026 YTD. Это описательная временная проверка без границ и поиска комбинаций; 2026 уже исследован V20, поэтому **не независимый TRUE OOS / holdout PASS**. Для корреляций не заявляется iid-значимость.

|---|---:|---:|---:|---:|---:|---:|
| Shallow | +0.038 / -0.210 | +0.006 / +0.015 | +0.002 / -0.077 | -0.083 / -0.058 | +0.159 / -0.145 | -0.000 / -0.148 |
| OBV | -0.029 / -0.180 | +0.095 / +0.010 | -0.030 / -0.112 | -0.146 / -0.172 | +0.086 / -0.070 | -0.078 / -0.118 |
| Inside | -0.225 / -0.332 | -0.001 / -0.166 | -0.174 / -0.410 | +0.266 / -0.254 | +0.174 / -0.199 | +0.330 / -0.429 |

В частности, у Inside знак связи давления и сжатия меняется; release-quality `+0,330 → −0,429` на 68 / 58 наблюдаемых признаках. У Shallow ratio `+0,159 → −0,145`. Даже одинаковый знак некоторых связей не доказывает переносимость или границы классов: сигналы зависимы, состав N4 меняется, выборка Inside мала, часть окон неполна.

**Вывод:** temporal causality расчёта проверена, причинный эффект режима и устойчивое правило трёх статусов не установлены. Из этих корреляций не выбирались пороги, не исключались инструменты, не оптимизировались PF/стопы/сроки. Профиль пригодности не создан.

Для `ДОПУСТИМО` нужен заранее зафиксированный компактный профиль, обоснованный исследованием пяти аспектов, и устойчивое различие последующих raw-исходов на отдельно проверенном времени/инструменте. `НЕДОПУСТИМО` требует столь же проверенного неблагоприятного профиля. `НЕЙТРАЛЬНО` — только смешанная/пограничная область **такого проверенного правила**. Недостаток доказательств сейчас означает `НЕ ОЦЕНЕНО` для всех трёх; это не доказательство отсутствия любых рыночных зависимостей.
