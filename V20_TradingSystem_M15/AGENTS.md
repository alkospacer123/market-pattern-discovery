# V20_TradingSystem_M15 — локальные правила исследования рынка

**Решение владельца V20 от 22.10.2026 (приоритетно для файлов и работ только внутри данного каталога).**

1. Для проекта **V20_TradingSystem_M15** календарные 2025 и 2026 **не являются закрытым TRUE OOS**. Они входят вместе с 2018–2024 в доступную историю для **описательной READONLY-аналитики рыночной пригодности, raw-сигналов и ретроспективных причинных по времени карточек**. Это уточнение переопределяет только соответствующее ограничение общего корневого `AGENTS.md` **для V20**; в остальных проектах исходный запрет 2025 продолжает действовать.
2. **ZERO LOOK-AHEAD остаётся обязательным.** В расчёте на дату T допускаются только свечи, сигналы и горизонты, полностью завершившиеся до T. При тестировании предупреждений за 2019 год недопустимо использовать ориентиры, рассчитанные из 2023–2026, как будто их знали в 2019-м. 2026 — неполный YTD по дате имеющегося архива; не интерполировать.
3. Все годы, использованные при исследовании показателей/порогов, считаются **исследовательской историей, а не независимым OOS-доказательством**. Не объявлять ранжирование/вердикты валидированными на этой же истории. Frozen V20 три стратегии, N4, M15, NEXT_OPEN, 2×ATR14 Wilder, выход до начала третьей наблюдаемой сессии и независимые FINAM-счета не изменять.
4. Нет оптимизации торговых стратегий, PF, новых фильтров заявок, изменения H1/M15/FINAM, торговли LIVE, новых этапов roadmap. Существующий порядок **8 этапов/24 подэтапа** и общие правила root `AGENTS.md` (кроме уточнённого статуса 2025 в V20) продолжают действовать.
